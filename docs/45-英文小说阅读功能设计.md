# 45 · 英文小说阅读（读书）功能设计（定稿 · 四官拷问后）

> 定稿依据：`local/reading-design-draft.md` v1（过程稿，不入库）+ `docs/46` 四官拷问合流。
> 范围：**移动端真形态（/m/*，Capacitor WebView）**；桌面 Web 不做（组长 2026-09-10 明确）。
> 定位：README「演进方向① 词汇速记」的落地主体（阅读场景）——**沉浸阅读英文小说（纯文本）+
> 点词查义 + 生词本 + 笔记/批注/划词 + 听书（TTS 句级跟读高亮）**，学英语「浸」线延伸。

## 1. 用户路径

- 入口：学习页（/m/learn）模块列表「我的单词」（→ /m/vocab）与「书房」（→ /m/bookshelf）；
- 书架 → 书详情（封面卡/简介/章节目录/开始·继续 CTA）→ 阅读器；
- 阅读器：段落排版 → 点词查义（词卡 sheet）/ 划词批注（高亮 4 色 + 笔记）/ 生词标记 /
  听书（句级高亮 + 播放条）/ 设置（字号/行距/主题/音色）/ 进度（防抖保存 + 恢复定位）；
- 生词本 /m/vocab = **唯一生词入口**（UI 拷问 U-5：学习页「我的单词」收敛到本页）。

## 2. 数据模型（8 表 · 全 Python 写方 · 迁移 0010）

| 表 | 要点 |
|---|---|
| books | (title, author) 复合唯一（seed 幂等键，M-5）；level L1-L4；source public_domain；status draft/published/archived |
| book_chapters | content TEXT（段落 \n\n 分隔）；**content_version**（文本修订版本守卫，V-6）；(book_id, chapter_no) 唯一 |
| dictionary_entries | word 唯一（ECDICT sw 口径归一）；phonetic/translation/definition；**exchange jsonb**（词形，V-5）；frequency（**位次**，越小越常见） |
| dictionary_forms | 词形反向索引（seed 由 exchange 派生；"inventions" → "invention"） |
| user_reading_progress | **PK(user_id, book_id) 单行 upsert**（V-12：不建历史表）；char_offset 章内 int；content_version |
| user_vocabulary | unique(user_id, word)；**词形→头词入库**（context_snippet 存原句）；scene reading/community/manual（预留）；status new/learning/known；chapter_id SET NULL；first-write-wins（V-10） |
| reading_annotations | kind highlight/note；start/end_offset 章内 char offset 主锚 + content_version 守卫 + sentence_idx 重锚助手 + text_snippet 快照；越界 45004（V-6/V-13） |
| tts_tasks | 状态机 queued/running/done/failed/cancelled；error jsonb；cancel_reason/cancelled_at；30 天物理删（操作日志性质，V-11） |

写方矩阵（docs/10 §3 增补）：**全部 Python；Java 零改动**；check_single_writer 无需豁免。
管理端后置：books 未来转 Java 编辑 → Single-Writer 反转 + content_version 守卫生效（V-1）。

**坐标系（V-20）**：annotations/progress 的 offset 均为章节正文整文本 char offset，
与 `app/reading/split.py::split_chapter` 输出同源；句级对齐免 ASR（VoiceStudio 复核结论：
逐 span 独立合成 → 以样本数得时长 → 前端 currentTime 反查；词级对齐登记 P2）。

## 3. 句子切分（服务端唯一权威）

- `split_chapter(content) -> {paragraphs, sentences:[{idx,text,para_idx,start,end}]}`：
  复用 `textproc/sentence_splitter.py`（宁可少切不可误切；缩写/小数/网址/括号 tag 全守卫）；
- GET /chapters/{id} 返回 content + paragraphs + sentences；前端「渲染用段落、播放/批注用句子 idx 与 offset」；
- 词块切分（前端纯函数 `audio/reader-words.ts`）：`splitPieceWords`（保留空白/标点偏移连续）；
  划词批注 v1 **仅句内**（跨句选区忽略，docs/45 §6 登记）。

## 4. API 契约（`/api/v1/reading` · 20 ops · 错误码 45xxx）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /books?cursor=&level= | 书架（keyset 升序；含我的进度） |
| GET | /books/{book_id} | 详情 + 章节列表（已读标记） |
| GET | /chapters/{chapter_id} | content + paragraphs + sentences |
| POST | /lookup | {word} → 头词条目 + 已入生词本；未收录 **404/45003** |
| POST | /vocab | 幂等添加（词形→头词入库；added 标记） |
| GET | /vocab?status=&cursor= | keyset（created_at\|id）；join 词典音标/释义/词频 |
| PATCH/DELETE | /vocab/{id} | status/note；删除（40401 不存在） |
| GET/POST/PATCH/DELETE | /annotations… | 本章批注 CRUD；偏移越界 400/45004 |
| GET/PUT | /progress/{book_id} | 单行 upsert |
| GET | /voices | edge 精选 5 + kitten 8（可用才返回） |
| GET | /chapters/{id}/tts/segment/{idx} | **audio/mpeg|wav 直出**（播放即取；命中缓存 0 扣） |
| GET | /tts/word/{word} | 词卡读音（同缓存与桶） |
| POST | /chapters/{id}/tts/prepare | **SSE**：task_start → sentence_progress* → task_done（心跳复用 sse_heartbeat_seconds） |
| GET | /tts/tasks/{id} | 进度快照（重连/刷新兜底；after_seq 登记 P2） |
| DELETE | /tts/tasks/{id} | 取消（user 原因落库） |

要点（docs/46 B 系列）：
- **只扣真实合成**（B-4）：segment 命中缓存 0 扣；未命中先扣后合成；prepare 按章扣 1；
  reading_tts 桶默认 **600/时**（听书一章 ~200 句；config `APP_READING_TTS_RATE_PER_HOUR`）；
- 缓存按 **provider 分目录**（B-3）：edge→`cache/tts/edge/*.tts.mp3`、kitten→`cache/tts/kitten/*.tts.wav`
  （防 wav 标 audio/mpeg 播坏）；键复用 tts_cache_key（provider|engine|voice|rate|text）；
- 音频端点裸流（非 Envelope，同 practice 例外登记，docs/21 §1.1）。

## 5. 听书 TTS（参考 VoiceStudio · AGPL 红线：只借思路零拷贝）

- **Provider 链**（`app/reading/tts_client.py::get_reading_tts_client`，与 get_tts_client 隔离，M-10）：
  - `auto`（默认）：kitten 可用（模型目录 + kittentts/onnxruntime 可导入）→ kitten；否则 edge；
  - `edge`：既有 EdgeTTSClient（en-US-Jenny/Guy/Aria、en-GB-Sonia/Ryan 精选）；
  - `kitten`：KittenTTS mini 0.8（78MB ONNX · CPU 实时 · **Apache-2.0** · 8 内置英文音色
    Bella/Jasper/Luna/Bruno/Rosie/Hugo/Kiki/Leo）；模型路径 `APP_VOICE_MODELS_DIR`
    （机器本地引用 VoiceStudio 缓存目录，**模型权重不入库**红线）；
  - azure/voicestudio-http/cosyvoice/voxcpm/omnivoice：**登记后置/不做**——
    OmniVoice 权重 CC-BY-NC 禁商用；CosyVoice3/VoxCPM2 需 GPU；VoiceStudio HTTP（:3900 无鉴权）
    仅限本机 loopback 使用，如需接入另行评估（docs/46 模型清单报告）；
- `kittentts` 为可选依赖：`uv sync --extra local-tts`（pyproject optional-dependencies）；
- **倍速 = 前端 playbackRate**（0.75/1.0/1.25/1.5 四档，docs/45 §5 拍板：免多档重合成）；
- **句级对齐**：当前句高亮（background 色）+ 自动滚动（viewport 15%~75% 外才滚，U 系列）；
- 整章预合成 = VoiceStudio jobs 模式借鉴（状态机 + 进度事件 + 取消 + 启动扫孤儿 → failed；
  失败句由「播放即取」实时补合成）。

## 6. 前端（移动端 · u-* 设计语言）

- **一致性裁定（U 系列）**：阅读功能用 **`u-*`（mobile-uic.css）**——当前 14 个 /m/* 页面的
  真实语言；MASTER/docs31 暖色未在代码落地、mobile-soft.s-* 仅登录页 → 不用于本功能；
  新增类全部 **`u-rd-*` / `u-bs-*` / `u-bd-*` / `u-vb-*`** 前缀（U-22，避免类名跨语义复用）；
  正文衬线 `--ur-font-serif`（内容层单一豁免），工具层仍 sans；
- 路由：`/m/bookshelf`、`/m/books/:bookId`、`/m/reader/:chapterId`、`/m/vocab`（requiresAuth）；
  **MobileTabBar group 增补**（U-4）：书架/书详情/生词本 → learn 组（有底栏）；阅读器保持沉浸（null）；
- 组件：MobileBookCover / MobileWordCard（词卡 sheet）/ MobileTtsBar（播放条）/
  MobileReaderBar（工具条）/ MobileAnnotationSheet（批注编辑/列表）/ MobileReaderSettingsSheet /
  MobileReaderTocSheet；
- composables（fe-08 行数门禁：阅读器 ~310 行，新代码不进灰名单）：
  useChapterTts（单元素顺序播放 + 预取 3 + Blob LRU≤12）/ useChapterPrep（SSE 进度）/
  useWordLookup / useReaderAnnotations（句内划选）/ useReaderProgress（防抖 + flush + 恢复）；
- 交互要点（U 系列裁定）：
  - 点词查义：词卡 = **底部 sheet**（非词旁 popover）；「加入生词本」主 CTA 炭黑 u-btn--primary
    （截图的蓝是强调色，非 u-* 主 CTA）；未收录 → 「暂无释义 + 外链 + 加入生词本」；
  - 划词批注：window.getSelection → selectionchange（200ms 防抖）→ 浮动 sheet（4 色 + 笔记）；
    与听书互斥：划选时 tts.pause()（U 系列）；
  - 生词标记：已入本词淡黄底 .is-word（点击直达词卡）；
  - 听书：播放/暂停/上句/下句/倍速/音色（设置 sheet）/预合成进度条；当前句高亮 + scrollIntoView；
  - 阅读设置：字号 16/19/22 · 行距 1.7/1.85/2.0 · 主题 纸白/米黄/暗黑（localStorage）；
  - 进度：滚动防抖 1s + 退出 flush + 进入恢复（章内首可见句 start offset）。
- 埋点：5 类新事件 `word_lookup / vocab_add / annotation_add / tts_play / tts_prepare`
  **四处同步**（B-15）：base.py EventTypes + analytics CHECK + 迁移 0010 扩 CHECK + 前端 EventName；
  页面曝光走既有 page_view。
