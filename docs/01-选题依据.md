# 01 · 选题依据

## 课题来源

课程《人工智能开发选题案例介绍》案例 **#7：基于大模型场景扮演的英语口语训练系统**（真实项目：面向互联网用户的语音口语学习平台）。

### 案例核心功能（原文要求）

- **海量学习资源整合**：电影、电视剧、新闻广播、有声读物等听说素材
- **实时反馈与智能评估**：语音识别 + 智能评估，实时指出发音、语法、流利度问题并给出改进建议
- **社交互动**：学习社区，交流心得、互相练习
- **个性化学习方案**：注册/入学测试 → AI 评估水平 → 自动生成个性化内容与练习计划
- **情景模拟与互动练习**：生活/工作/学习场景模拟对话，与 AI 数字人互动
- **可视化报表**：口语考试成绩多维度分析展示

### 原文标注的技术点

人机对话 · 场景模拟 · 语音合成和识别 · 发音评分 · 交互数字人

### 原文标注的开发语言/模型训练

- 后端：Python（数据处理、模型部署）、Java（系统架构、工单管理）
- 前端：Vue（Web 端界面）、Android/iOS（移动端 App，Kotlin/Objective-C）
- 模型训练：**PyTorch / TensorFlow**（深度学习模型开发）+ **Scikit-learn**（推荐、口语水平预测）—— 本课题"轻训练"重点：发音评分模型微调（GPU 20~40 小时量级）+ 推荐/水平预测模型（CPU）

### 原文建议的推荐策略（检查点指标）

- 学习内容推荐（兴趣 + 历史相似/拓展）
- 协同过滤推荐（相似用户特征和行为）
- 模型预测推荐（机器学习算法构建**口语水平预测模型**）
- 检测指标：**点击率、完成率、互动率、跳出率**

## 本项目扩展方向

在原案例基础上增加特色模块：

1. **英文歌练唱评分**：跟唱英文歌，对音准（基频）、节奏（歌词时间戳对齐）、发音逐句打分。技术：pyin/crepe 基频提取 + DTW 时间对齐（CPU 可跑，无需 GPU），与已有语音管线天然融合。
2. **产品化定位**：平台名 `VocalVerse 声语界`，走"口语 + 唱歌"双场景，差异化于市面单一口语 App。

## 结题检查点（答辩口径）

- 口语练习全流程可用：录音 → 转写 → 评分 → 改进建议 → 报告
- 唱歌评分可演示：任意英文歌 LRC 歌词时间戳 + 用户跟唱 → 逐句音准/节奏得分
- 个性化推荐生效：不同水平/兴趣用户得到不同练习内容（用模拟行为数据验证）
- 四项指标：点击率、完成率、互动率、跳出率（埋点统计；精确定义见 `docs/06` 第 9.1 节）
- 自研加分项：wav2vec2 发音评分微调（GPU 约 ¥50~110）替代纯 API 方案
