## 5. S1 详细设计 · 波形回放组件（wavesurfer.js）

### 5.1 切口契约

- **登记先行**：docs/06 §3 版本矩阵 + docs/13 §5 依赖纪律 → 再写代码。
- **包**：`wavesurfer.js@^7.12.11`（⚠️ 勿装占位包 `wavesurfer@1.3.4`）；**动态 import**（`import('wavesurfer')` + 组件内 async 加载，>100KB 按 docs/13 §5.2 砍首包）。
- **组件边界**（防止 F6 四套播放逻辑）：`WaveformPlayer.vue` 只接受 `blob: Blob | null` + `regions: WaveformRegion[]`（`{start,end,label}` 手写共享类型，不进 gen:api）；**不接受远程 URL**（R-5 鉴权冲突，业务侧 fetch+Blob 已由轴线E Q10 定案）；内部 `AudioContext.resume()`（iOS 手势内）、`play()` NotAllowedAbort 兜底（八约束 #7）。
- **事件**：emit `play/pause/ended`；`defineExpose` 播放/暂停/seek/setPlaybackRate/clearRegions。
- **与既有播放的合并策略**：M3 唱歌报告页 = 首真消费方；**ShadowPreview 保持现状**（S3 时才替换）；PracticeView/DefenseView 的 `new Audio` 播放 TTS 队列**本次不动**（它们是流式队列播放，非回放组件职责）。

### 5.2 测试与门禁

- 单测：组件逻辑薄（控制器对 wavesurfer 的包装要薄 + `container` 元素注入便于测试）；happy-dom 缺 canvas → 组件测试降级为「blob 校验 + 事件转发」mock 层；波形真实渲染以「组件展示页 + 真机打点」（§8 实测表 #8/#附 音频回放行）为准。
- 门禁：`pnpm lint && pnpm typecheck && pnpm test:run && pnpm build`；生产构建确认预览子树 + wavesurfer **零残留**；删除清单：展示页三行 + 组件随 M3 页保留。

## 6. S2 详细设计 · ASR 降级引擎（sherpa-onnx）

### 6.1 实现步骤（G4/G5/G7/G10 裁决后）

1. **信号量前置（G11）**：`app/audio/asr.py` 现有 `asyncio.to_thread` 之外补 `asyncio.Semaphore(2)`（与 ISE 一致），兑现 docs/06 §8；补 compose `hf-cache` 卷。
2. **依赖**：`pyproject.toml` `[project.optional-dependencies] asr-fallback = ["sherpa-onnx>=…"]`；`uv lock` 刷新（CI `--frozen` 自动守护）。
3. **组合器**（不改接口）：`class FallbackASRClient(ASRClient)` 持 `primary` + `fallback`；`transcribe()`：主抛错 → `logger.warning(engine=…)` → 备；`asr_fallback_enabled=False` 时直接返回 primary（零行为变化）。
4. **判定语义**：`ASRResult` 增加**非破坏性判别**——主返回空文本且 `no_speech` 类信号 → 视为「成功但空」直接上抛（不降级）；仅异常/超时（<5s，复用 http 超时语义）才降级。
5. **预热**：`FallbackASRClient` 透传 `_get_model`/warm；`main.py::_prewarm_asr` 判断**双引擎都预热**或（备未启用时）仅主。
6. **模型**：独立目录 `data/models/sherpa/`（gitignored）+ **新建 `scripts/setup-assets.ps1`**（对应 docs/06 §9.7 死引用；或改文档）；**.gitignore 补 `data/models/**`（防 fixtures 豁免误入库）**；模型许可核验留痕（写入脚本注释 + 文档）。
7. **配置**：`asr_fallback_enabled: bool = False`（注释「验证开关，产品化再评估默认开」）+ `sherpa_model_dir: str` + `sherpa_tokens: str` + `sherpa_provider`（如 paraformer/whisper tiny 档，先 POC 定）。
8. **契约**：零新路由（G8）；`/readyz` 仅全缺时才 degraded（G10）；SSE 字段不动（G9）。

### 6.2 测试（TDD：修复前必失败）

| 用例 | 断言 | 修复前状态 |
|---|---|---|
| 主引擎抛错 → 走备引擎并返回完整 ASRResult（键非空） | `engine 字段 = "fallback"`，words/segments 结构完整 | 无组合器 → 失败 |
| 主引擎成功但空转写（静音）→ **不降级** | fallback 调用计数 = 0 | 无判定语义 → 失败 |
| `asr_fallback_enabled=False` → 行为与现状完全一致 | fallback 引用计数 = 0，返回值与 primary 相同 | 失败 |
| 备引擎也失败 → 上抛原错误（不吞） | 异常类型保持 | 失败 |

- 注入方式：**直接实例化组合器**注入 fake 主/备（绕开 `APP_TESTING` 全局 Fake 短路），仿 `test_agent_lab`/`test_shadow` 函数级导入模式。
- 门禁：`uv run ruff check . && uv run ruff format --check . && uv run pytest -q`（sherpa 真引擎测试标 `@pytest.mark.gpu`/skip，CI 默认不下载模型）+ 契约快照零 diff（无新路由自然成立）。
