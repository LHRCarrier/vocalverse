## 1. 图标库选型

### 1.2 选型结论

- **主选：Tabler Icons** —— 全部图标统一 2px 圆头圆角、24px 视口（贴合 Plus Jakarta Sans 圆润气质）、
  同库 line→filled 后缀切换（`tabler:star` ↔ `tabler:star-filled`）、MIT、Vue 一等公民、语义覆盖我们全部场景。
- **特殊场景：Phosphor**（经 unplugin + `@iconify-json/ph`）——fill/duotone 做**深蓝渐变焦点卡/登录大图形/实心强调**，
  是唯一一个库内提供完整权重梯度的；官方 Vue 包已停更，**不要**直接安装 `@phosphor-icons/vue`。
- **对比基准：Lucide**（ISC）——更极简克制；如未来审美倾向"更冷"，可整体替换主基调（纯 line，需另配填充方案）。
- **接入方式：`unplugin-icons` 编译期按需内联 SVG** —— 运行时零库开销、WebView 离线最优、`currentColor` 天然换肤、
  线/填充同前缀切换；**不用** `@iconify/vue` 运行时整集（包体大、换肤/离线不友好）。
  少数自绘品牌件（logo/波形/评分星）走 `assets/` + `<Icon>` 包装。

## 2. UI 组件库 / 基座模式选型

### 2.1 结论：自研 `s-` 体系 = 「reka-ui（unstyled 基座）+ cva（变体编排）+ 自研三层 CSS token」

- **采纳**：`reka-ui`（MIT，Radix Vue 继任者，unstyled 行为/无障碍基座：focus/键盘/ARIA/焦点陷阱/滚动锁定）；
  `class-variance-authority`（MIT，框架无关变体编排，配 `clsx`）；三层 token（primitive→semantic→component，已在做）。
- **只抄模式不抄堆栈**：参考 shadcn-vue 的「拷贝归仓 + 自有皮肤」，但**不搬它的 Tailwind 原子类栈**
  （带入不需要的视觉栈 + 常年翻译/merge/适配上游，UnoCSS 侧适配版本滞后——unocss-preset-shadcn issue #20/#23）。
- **不纯自研**：无障碍细节（焦点陷阱/键盘/ARIA）是重造轮子且易回归；自研的是**视觉**，复用别人打磨好的**行为**。
- reka-ui 用：Dialog/Popover/Overlay、Dropdown/Select、Tooltip、Tabs、Switch、RadioGroup、**Slider**、Toast；
  自研：纯展示件、品牌款、底部 Tab/分段控件（结构简单、纯品牌件）。
- **Naive UI**：**保留给 Web 管理端**，只做有边界 `themeOverrides`（品牌色+字体族+圆角）"沾点品牌"；
  **不搬进移动端**（字级/间距自成体系，全量换肤成本高风险中，且不该带进 WebView 包）。
- **排除**：Vant/NutUI（品牌冲突+异己 DOM+rem 体系冲突，为 5 个组件引整套移动库不划算）、
  Element Plus / Ant Design Vue（不搭）、panda-css（与 UnoCSS+token 重复）。
- **参考**：PrimeVue（unstyled/passthrough 模式范本）、Nuxt UI（reka-ui+自有 token 工程化实例）、HyperUI、radix-ui primitives。

### 2.2 动效层

- **基座：VueUse**（`useSpring`/`useTransition` + `useReducedMotion` 门控）——极轻、tree-shakable；
- **增强：Motion for Vue（motion.dev）**——spring 物理 + variants，基于 transform/opacity，内置 reduced-motion；
- **路由级：View Transitions API**（渐进增强，Android WebView 支持不均衡，作叠加不做主方案）；
- **排除：GSAP**——超出「只动 transform/opacity」所需，体积/复杂度不划算；
- 纪律：全链路只动 transform/opacity（合成器友好→WebView 60fps），统一 `@media (prefers-reduced-motion: reduce)` 降级。

## 3. 许可合规（进仓库/打包必做）

1. 库存 `docs/assets/ui-lib-reference/licenses/`（Tabler MIT / Phosphor MIT / Lucide **ISC** / unplugin-icons MIT）；
2. Iconify 逐集核验（本目录三份数据集已对号）；生产只用 MIT/ISC 明文可再分发库；
3. 回避：Streamline（付费）、SF Symbols（Apple 专有）、Untitled UI/Hugeicons（免署名+不可再分发）、
   `@remixicon/vue`（自定义许可）、Font Awesome（CC BY 署名）；
4. 商标图标仅作功能示意；构建产物附「所用图标+归属库+许可」清单。

## 4. 落地步骤（与 docs/31 §5 衔接）

1. 样板页（首页/登录 v3.1）接入：`unplugin-icons` + `@iconify-json/tabler`（主）+ `@iconify-json/ph`（大图形）；
   自绘声波 logo/波形组件；
2. 控件层：已有 s- 组件升级为 cva 变体编排；弹层/Toast/Slider 后续按需引 reka-ui；
3. 动效：先在动画点试用 VueUse `useReducedMotion` 门控 + CSS transform/opacity；弹簧态按需 Motion for Vue；
4. 管理端：Naive `themeOverrides` 对齐品牌色/字体/圆角（低风险项）。
