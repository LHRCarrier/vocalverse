## 1. 设计 Token（实现：`apps/web/src/styles/tokens.ts`）

改风格只改 `tokens.ts` + 本文件；css 里 hex 一律引用 token 或 uno.config 映射。

### 1.1 色彩（B 多邻国活力）

| Token | 值 | 用途 | 注意 |
|---|---|---|---|
| brand | `#16A34A`（绿） | 主色：按钮底/品牌图形/Nav 强调 | 白字对比度≈3.3:1，仅用于大字/图形，不做正文 |
| brandLight | `#22C55E` | hover/鼓励图形 | - |
| brandDeep | `#15803D` | **文字级绿色**（链接/强调正文） | AA 对比度 ✓ |
| accent | `#FACC15`（柠檬黄） | 徽章/激励/录音态 | 配深色文字 `#101828` |
| score | `#FB923C`（橙） | 评分/高亮 | 配深色文字 |
| success / error / info | `#22C55E` / `#EF4444` / `#0EA5E9` | 状态语义 | - |
| bg / bgBrand / card | `#F9FAFB` / `#ECFDF5` / `#FFFFFF` | 页面底/品牌浅底/卡片 | - |
| text / textSecondary / border | `#101828` / `#667085` / `#E5E7EB` | 正文/次文/描边 | - |

### 1.2 其他

- 圆角：组件 8px / 卡片 12px / 胶囊 999px（按钮统一胶囊化，多邻国式圆润）
- 间距：4 基元 `[4, 8, 12, 16, 24, 32]`；页面内容宽度 max 1080px
- 字体：`Nunito, ui-rounded, system-ui, …苹方/雅黑`（Nunito 为可选外网字体，断网回退系统栈，不阻塞演示）
- **本期只做浅色模式**；深色列扩展（1 人前端，双主题=双倍回归成本）

## 2. 三层样式架构（防"各写各的"）

```
naive-ui（组件层） → 按钮/表单/表格/弹窗；样式仅经 themeOverrides（src/styles/theme.ts），禁止改组件源码
UnoCSS（布局层）  → padding/gap/flex/文本尺寸等工具类；设计语义（品牌色）用 uno.config 映射的 bg-brand 等
tokens（设计层）  → src/styles/tokens.ts 唯一来源；色值/圆角/字体
```

## 4. 动效与可视化栈

| 库 | 允许范围 | 纪律 |
|---|---|---|
| **ECharts ^6** | M3 报表：趋势折线/维度雷达/四指标卡 | `import * as echarts from 'echarts/core'` 按需注册；按页懒加载 |
| **P5.js ^1.11** | **仅品牌动效 1~2 处**：登录页声波（已实现 `useP5Wave`）、录音波纹（M2 加） | 动态 `import('p5')` 不进首屏；失败静默降级 CSS；组件卸载必须 `remove()` |
| **D3 ^7** | **仅唱歌评分"逐句音准/对齐图"**深度定制（M3） | 其余图表禁止用 D3（成本高 3~5 倍） |
| ~~Three.js~~ | **不引入** | 与 docs/06 §9.2 "2D 数字人 + 不做 3D/口型"拍板冲突；3D 场景=答辩风险（"对训练价值的贡献"）。替代：canvas/CSS 动效 |

## 5. 开发约定

1. 新组件库选型必须先登记 docs/06 §3 版本矩阵（P1-#8 纪律），再进代码；
2. vite 懒加载：任何 >100KB 的库都按页动态 import（当前 p5/echarts 均如此，打包时看 chunk 归属）；
3. 组件测试环境 = happy-dom（`vite.config.ts` test 段）；组件测试覆盖纯逻辑优先（评分公式/指标计算）；
4. 文案：产品名「VocalVerse 声语界」；品牌口号「说得好，唱得准 —— AI 发音教练」。

## 6. 答辩口径（被问"为什么这套"）

> "组件库以 TS 类型与主题定制能力为核心选型：naive-ui 提供一等 TS 支持和 token 化主题覆盖；布局工具类用 UnoCSS 防三人风格漂移；设计 token 统一色彩，改风格只改一处。视觉走游戏化活力路线（参照学习动机已验证的配色逻辑：绿=进步、黄=激励、橙=评分），因为本产品面向'坚持练习'的学习动机设计，与完成率/互动率指标目标一致。动效库只用于品牌记忆点（录音声波），图表 M3 用 ECharts 快速交付、唱歌对齐图用 D3 深度定制；未引入 Three.js——3D 数字人与本产品已拍板的 2D 演示口径冲突，我们选择把成本投在评分准度上。"
