## 1. 设计 Token（实现：`apps/web/src/styles/tokens.ts`）

改风格只改 `tokens.ts` + 本文件；css 里 hex 一律引用 token 或 uno.config 映射。

### 1.1 色彩（B 多邻国活力）

| Token | 值 | 用途 | 注意 |
|---|---|---|---|
| brand | `#16A34A`（绿） | 主色：按钮底/品牌图形/Nav 强调 | 白字对比度≈3.3:1，仅用于大字/图形，不做正文 |

### 1.2 其他

- 圆角：组件 8px / 卡片 12px / 胶囊 999px（按钮统一胶囊化，多邻国式圆润）
- 间距：4 基元 `[4, 8, 12, 16, 24, 32]`；页面内容宽度 max 1080px
- 字体：`Nunito, ui-rounded, system-ui, …苹方/雅黑`（Nunito 为可选外网字体，断网回退系统栈，不阻塞演示）
- **本期只做浅色模式**；深色列扩展（1 人前端，双主题=双倍回归成本）

## 2. 三层样式架构（防"各写各的"）

```
naive-ui（组件层） → 按钮/表单/表格/弹窗；样式仅经 themeOverrides（src/styles/theme.ts），禁止改组件源码
UnoCSS（布局层）  → padding/gap/flex/文本尺寸等工具类；设计语义（品牌色）用 uno.config 映射的 bg-brand 等
tokens（设计层）  → src/styles/tokens.ts 唯一来源；色值/圆角/字体
```

## 4. 动效与可视化栈

| 库 | 允许范围 | 纪律 |

## 5. 开发约定

1. 新组件库选型必须先登记 docs/06 §3 版本矩阵（P1-#8 纪律），再进代码；
2. vite 懒加载：任何 >100KB 的库都按页动态 import（当前 p5/echarts 均如此，打包时看 chunk 归属）；
3. 组件测试环境 = happy-dom（`vite.config.ts` test 段）；组件测试覆盖纯逻辑优先（评分公式/指标计算）；
4. 文案：产品名「VocalVerse 声语界」；品牌口号「说得好，唱得准 —— AI 发音教练」。

## 6. 答辩口径（被问"为什么这套"）

> "组件库以 TS 类型与主题定制能力为核心选型：naive-ui 提供一等 TS 支持和 token 化主题覆盖；布局工具类用 UnoCSS 防三人风格漂移；设计 token 统一色彩，改风格只改一处。视觉走游戏化活力路线（参照学习动机已验证的配色逻辑：绿=进步、黄=激励、橙=评分），因为本产品面向'坚持练习'的学习动机设计，与完成率/互动率指标目标一致。动效库只用于品牌记忆点（录音声波），图表 M3 用 ECharts 快速交付、唱歌对齐图用 D3 深度定制；未引入 Three.js——3D 数字人与本产品已拍板的 2D 演示口径冲突，我们选择把成本投在评分准度上。"

## 8. 预览工作流（preview → 验收 → 集成，团队约定，2026-08-31 定）

每个新功能页面（含管理端模块）都走一遍：

```
1. 需求拍板     功能本体按 docs/06 §9 口径，不新发明；体验增强候选按群内拍板清单
2. 静态高保真   apps/web/src/views/preview/* —— 复用 tokens/主题/布局组件（token 零漂移）
               新增预览页 = ① src/router/preview.ts 加路由 ② src/views/preview/registry.ts 登记（画廊菜单）
3. 视觉验收     组长/前端按下方验收表勾选 → 不达标改 preview，主代码不动
4. 集成 = 平移 + 删除   预览页复制为 src/views/* 真实 view（接 API）后，
               **删除该预览页 + 撤 registry 登记**——预览页只代表"未集成的未来页"，
               绝不保留两份同款代码（防漂移；2026-08-31 修订"保留作回归对照"的旧决定）
```

- **生产剔除机制（上线零残留）**：预览整棵子树包在 `import.meta.env.DEV` 三元内——生产构建常量折叠后连根剔除（已验证 dist 零 Preview chunk、无路由）；**无需任何上线操作**。若 M4 前决定不再走预览流程，清理仅 3 处：删 `src/views/preview/` + `src/router/preview.ts` + `src/router/index.ts` 的 import/插入两行；建议保留机制（M3/M4 加页面仍要用）。
- **通道**：`/preview` 画廊（仅 DEV：`import.meta.env.DEV` 常量折叠，生产构建整支剔除——已验证零 chunk）
- **布局模拟模式**（2026-08-31 盲点修正）：预览页在 `registry.ts` 登记 `layout`（user/admin），画廊默认以**真实布局**（UserLayout/AdminLayout）包裹渲染——TopNav/侧边栏关系与集成后一致（所见即生产）；右上角可切换 画廊/用户端/管理端 三种模式对比
- **验收表**（"效果达标"写死这些维度，防主观）：
  - 风格统一：页面内 hex 必须来自 `tokens.ts` 或 uno.config 映射（0 硬编码）
  - 对比度：文字级绿 `#15803D`；黄/橙配深色文字 `#101828`；正文 `#667085` 不得低于 12px
  - 节奏：间距 4 基元；内容宽 1080 / 卡片流；圆角 8/12/胶囊 900
  - 断点 768/1280 可用；空状态 + 首次引导态齐全
  - 动效 ≤2 处/页；懒加载 + 失败降级（P5/ECharts 均动态 import）
- **现成预览页**：home（学习主页）/ practice（场景对话 ★核心）/ report（评分报告）/ admin-dashboard（评价看板·ECharts 可视化）/ admin-users（用户管理表格）
