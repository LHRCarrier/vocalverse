### 1.2 一句话定位（事实 + 分析）

官方口径：「轻松学英语，用人工智能老师」——以自研 AI 语音评测与深度自适应学习系统驱动的、系统化的英语听说读写解决方案（[官网首页](https://www.liulishuo.com/)、[官网·AI 技术](https://www.liulishuo.com/tech.html)）。

**分析：** 更精确的定位是「用 AI 把标准化英语课程的边际服务成本压到接近零的**课程分发与训练平台**」。它的内核不是"陪你聊天"，而是"把一套 8 级课程用自适应算法喂给你，并用语音评分逼你张嘴"。这一条对 VocalVerse 极其关键——它与我们的产品形态（LLM 驱动的开放场景扮演）在**范式上不同代**。

## 二、核心功能拆解

### 2.1 口语练习的核心玩法：**是"课程化跟读 + 结构化答题"，不是"开放场景扮演"**（事实 + 分析）

官方描述的能力项为：
- 「懂你英语®A⁺」核心课程：自适应诊断测试 + AI 老师按优势/薄弱点调整学习节奏
- 配音课程：14 个分类的视频片段配音
- 每日更新的地道实用英语对话（带动口语/单词/语法/听力/阅读）
- **真人语伴互动学习**：按等级匹配真人语伴进行英语互动对话 + 答题 PK
- 「会打分的口语外教」：内置语音识别技术实时打分、矫正发音

（以上均出自 [App Store 官方描述](https://apps.apple.com/cn/app/id597364850) 与 [豌豆荚官方版描述](https://www.wandoujia.com/apps/com.liulishuo.engzo)，对应版本 10.5.19 / 2026-08-27）

**分析：** 官方对外描述中，"多轮对话"的承载者是**真人语伴**（人机匹配的社交对话），而 AI 承担的是**评分**与**路径调度**。课程内的"对话"是编排好的教材素材（跟读、复述、选择、配音），属于**脚本化对话**而非**开放式角色扮演**。也就是说：流利说的口语训练范式 = 受控输入 + 受控输出 + 打分，**输出的自由度被刻意压低以保证可评测性**。这正是它与 LLM 时代产品的分水岭。

### 2.2 发音评分粒度与技术（事实，来源权威度高）

官网「AI 技术」页给出了明确口径：

- **粒度**：能够在**句子层面、单词层面、音素层面**打分
- **维度**：音准、流利度、完整度、连读、重音、语调等多维度细致打分
- **蓝本**：以美音母语者的语音数据为蓝本
- **语音识别**：可将英语语音转写为文字（含大小写与基础标点），并强调"可准确识别中式英语"
- **数据壁垒**：中国人英语语音数据库，累计录音 433 亿句、32 亿分钟（数据截至 2019-12-31）；关于我们页更新为截至 2022-06-30 约 40 亿分钟对话、537 亿句录音
- **语音合成**：自研 TTS，支持混合合成与"即时个性化声音定制"
- **语法检错**：支持拼写、主谓一致、动词形态、名词单复数等 **50+ 种错误检测**并给出纠错建议
- **组织**：在上海、杭州、美国硅谷设三地 AI 实验室；2020 年初其"学习与认知人工智能重点实验室"获评上海市级企业重点实验室

来源：[官网·AI 技术](https://www.liulishuo.com/tech.html)、[官网·关于我们](https://www.liulishuo.com/aboutus.html)

**分析：** 音素级评分 + 六维打分 + 超大规模中国人英语语音库，是流利说最硬的护城河，**且是 VocalVerse 无法用同等方式追赶的**。我们必须走"调用成熟评测能力/开源 GOP 方案 + 把反馈可解释性做深"的路线，而不是"自研更准的评分模型"。另外注意：官网把"语法检错"描述为对**英文文本**的分析（服务于写作打分引擎），**未见其宣称在口语多轮对话中做实时语法纠错**——这是一个可打的空档（详见第六章）。

### 2.3 入学测试与水平分级（事实）

- 有**定级测试（自适应诊断测试）**，据测试结果将学员分为 **8 个等级**
- 每级都有能力描述 + **对标托业/雅思分数区间**（如 Lv4 中级 ≈ 托业 650-750 / 雅思 5-6；Lv8 精通 ≈ 托业 950-990 / 雅思 9）
- 企业渠道课程页写明"与 CSE（中国英语能力等级量表）对标的英文综合能力测评"，课程覆盖 **CEFR 欧标 A1 至 C2 全等级**

来源：[官网·懂你英语](https://www.liulishuo.com/dongni.html)、[百仕瑞·流利说优选套餐（线上版）](https://keycourse.com/product/productDetail/625)

**分析：** "分级 + 对标国际量表"已经是这个品类的 **table stakes**。VocalVerse 的入学测试若只给一个"85 分"而不给 CEFR/CSE 对标位置，用户会立刻感到不专业。

### 2.4 个性化学习路径怎么生成（事实 + 官方效果数据）

- 定级测试结果决定起点等级，"智能算法深度分析学员学习行为与学习数据，并对其学习内容进行实时优化"
- 官方称其为「像 AlphaGo 一样智能的深度自适应学习系统」，宣称"颠覆传统知识图谱体系，构建全新教学模型"
- 教学理论支撑：**RHR 层级递归认知理论**，首席顾问为 Lance Knowles；强调"高频短时、科学有序""多感官输入"
- 官方公布的效果研究：746 位学习者平均学习 **36.88 小时**后，约 **40%** 提升至少一个欧标等级、**72%** 成绩有所提高；559 名测试者每使用 App 学习 1 小时，普思（Aptis）考试成绩平均提升 **0.324 分**（官方标注数据来源为英国大使馆文化教育处及英国贝德福特大学相关研究）

来源：[官网·懂你英语](https://www.liulishuo.com/dongni.html)

**分析：** 效果数据是流利说最值钱的营销资产：它把"AI 教育"从概念变成了可量化承诺。**VocalVerse 应当在项目内建立同构的效果度量机制**（如"练习 N 小时 → 评分提升 X"的回归曲线、A/B 对照），哪怕样本量只有几十人，这在需求报告与答辩中都是强论据。

### 2.5 内容资源来源与形态（事实）

- 自研课程体系：懂你英语 A⁺（A1–C2 八级、企业渠道称"1000+ 小时通用英语学习"）
- 商务英语 A⁺：10 大主题、70 个单元 / 70 张卡片、约 210–212 节课、11,163 道题目、135 个互动视频；分预备/进阶/高级/挑战四级；主题含英文面试、英文办公、公司介绍、商务会议、职场 Presentation、职场软技能、邮件写作、商务谈判、管理与领导力、行业英语拓展包
- 配音课：14 个分类的影视/搞笑/爱情/科技等视频片段
- 原声录制：官网称"美国新闻播音员原声录入"；流利说阅读聘美国专业播音员录制外刊音频，外刊来自《经济学人》《纽约时报》《卫报》，并含 70+ 本正版原版书籍
- 发音专项：流利说·发音、自然拼读、地道发音课程（见 App 内购列表）

来源：[百仕瑞课程页](https://keycourse.com/product/productDetail/625)、[教育在线 FAQ](https://gaokao.eol.cn/gzxy/yxdt/202607/t20260701_2751474.shtml)、[官网·懂你英语](https://www.liulishuo.com/dongni.html)、[官网·流利说阅读](https://www.liulishuo.com/vira.html)、[App Store](https://apps.apple.com/cn/app/id597364850)

**分析：** 内容是**重资产**：万级题目、百级视频、正版外刊与书籍授权。VocalVerse 用 LLM 动态生成场景剧本，边际内容成本趋近于零——这是我们唯一能在"内容广度"上抗衡的方式，但代价是**内容质量不稳定、无教研背书**，必须用"场景模板 + 教研规则 + 评审"兜底。

### 2.6 社交/社区功能（事实：**曾强，现弱**）

- 当前官方描述保留：真人在线对话（按等级匹配语伴）、答题 PK
- 私教课体系配套 **30 人小班社群** + 学习管理师带班、课前提醒、学习督导、作业点评（7 天内点评）、每月 1 次学习报告
- **用户端反馈显示社交功能被削减**：App Store 一条长评（2021-02-17，用户"//tttttay、、"）明确抱怨"以前的情景对话还有私信关注功能……现在是都没用了""那个时候甚至都没有了真人对话"，并请求恢复关注/私信；豌豆荚评论区亦有"一声不吭的把配音课取消了，差评"（2018-08-27）、"配音的课程怎么没了？"（2019-03-28）

来源：[App Store 用户评论](https://apps.apple.com/cn/app/id597364850)、[豌豆荚评论区](https://www.wandoujia.com/apps/com.liulishuo.engzo)、[教育在线 FAQ](https://gaokao.eol.cn/gzxy/yxdt/202607/t20260701_2751474.shtml)

**分析：** 流利说的社区是"运营型社群（付费用户督学）"而非"产品型社区（UGC 互动）"，且产品型社交能力在历史迭代中被砍掉过，留下了明确的用户怨气。这说明：**轻量社交对留存有价值，但重社交对这个品类不是必需品**——正好印证 VocalVerse 把社区列为 P2「最小实现」的决策是合理的。

### 2.7 数据报表与学习反馈（事实）

- 官网明确列出"灵活便捷 数据可视：学习数据全追踪，点滴进步一目了然"
- B 端/私教侧：管理者可视化管理服务、每月 1 次学习报告、作业点评
- 雅思产品线：模考后提供"权威分析报告"，从**词汇、发音、语法、流利度四大维度**给出口语分数摸底

来源：[官网·懂你英语](https://www.liulishuo.com/dongni.html)、[App Store 流利说雅思描述](https://apps.apple.com/cn/app/id1153192044)、[教育在线 FAQ](https://gaokao.eol.cn/gzxy/yxdt/202607/t20260701_2751474.shtml)

**分析：** 它的报表偏"进度与达标"（学了多久、过了几关、等级是否提升），**四维评分报告主要出现在雅思线**。"薄弱音素定位 → 针对性训练包"的闭环，在公开材料中未见完整呈现——这是 VocalVerse 报表模块可以做出差异的地方。

### 2.8 AI 大模型（LLM）使用情况（**关键结论：未见证据**）

**事实：**
- 截至 2026-09-01 核查，[App Store 官方描述（v10.5.19，2026-08-27 更新）](https://apps.apple.com/cn/app/id597364850)、[豌豆荚官方版描述](https://www.wandoujia.com/apps/com.liulishuo.engzo)、[官网 AI 技术页](https://www.liulishuo.com/tech.html) 中，**均未出现"大模型 / LLM / GPT / 自由对话 / AI 陪聊"等表述**；官网 AI 技术页列出的四项能力仍是语音识别、发音评测、语音合成、语法检错。
- 官网 AI 技术页与首页页脚版权信息仍为「© 2022 上海流利说信息技术有限公司」，新闻资讯页（news.html）当前无内容条目。
- 本次多轮检索**未能找到**流利说官方宣布接入大模型（自研或第三方）的可靠信源。

**标注：** 「流利说是否已在 App 内接入 LLM 做自由对话」——**未能核实**。本报告不主张"它一定没有"，只能确认"截至核查时点，其对外主推卖点中不包含 LLM 自由对话"。

**分析：** 这是本次竞品分析中最重要的一条。一家握有 537 亿句录音、三地 AI 实验室的公司，在对外物料上仍以"评分引擎 + 自适应课程"为核心叙事，说明其**产品形态被既有课程资产与商业模式锁定**（课程卖钱，自由对话不好卖也不好评分）。对 VocalVerse 而言，"LLM 驱动的开放场景扮演"不是"补它的课"，而是**在它的路径依赖之外开一条新赛道**。

## 四、优势（Strengths）

## 五、劣势（Weaknesses）

**W1｜交互范式停留在"跟读 + 答题 + 打分"，缺少开放式自由对话。**
截至 2026-09-01，其 App Store / 豌豆荚官方描述与官网 AI 技术页均无 LLM、自由对话相关表述，官方描述中承担"多轮互动"的是**真人语伴**而非 AI（[App Store](https://apps.apple.com/cn/app/id597364850)、[AI 技术页](https://www.liulishuo.com/tech.html)）。**分析：** 在 ChatGPT 之后成长起来的用户，对"我说什么系统都只回一个分数"的容忍度正在快速下降。这是它最大的产品级劣势，也是 VocalVerse 的主战场。

**W4｜性价比与内容质量遭质疑。**

**W5｜无 Web 学习端，端形态单一。**
官网仅承载营销与购买，学习闭环全在 App（[官网](https://www.liulishuo.com/)）。**分析：** 这在机房教学、企业办公场景、需要大屏/键盘输入的写作与面试练习中是明确短板。

**W7｜"AI 教育"的实际交付高度依赖真人。**

## 六、对 VocalVerse 的启示

### 6.1 必须抄的（table stakes，不做就没法比）

1. **入学测试 + 等级体系 + 国际量表对标**：至少给出 CEFR（A1–C2）或 CSE 对应位置，而不是裸分。对应 VocalVerse P0「注册/登录/学习档案 → 入学测试」。
2. **音素级发音评分 + 多维度打分**：音准、流利度、完整度、连读/重音/语调至少覆盖前三项；单纯给"总分"会被一眼看穿。对应 P0「口语评测」「发音纠正建议」。
3. **标准发音示范（TTS）与对比回放**：错了要能立刻听到"正确的是这样"，并可 A/B 对比自己的录音。
4. **自适应的学习路径 / 每日任务**：根据薄弱维度动态排任务，而不是固定课表。对应 P1「学习计划生成」。
5. **学习数据可视化**：趋势 + 雷达 + 薄弱项，且要能一眼看懂"我进步了没有"。对应 P1「可视化报表」。
6. **清晰的免费/付费（或开放/登录）边界与体验钩子**：把"测评 + 一次完整体验"放在门外，把"长期计划 + 报告"放在门内。
7. **打卡与坚持机制**：连续天数、每日目标、成绩卡片分享——这是留存的最低成本手段，对应 P2 社区最小版即可满足。
8. **语法/表达错误的分类化反馈**：流利说对文本做 50+ 种错误检测；我们至少要把对话中的错误归类为"语法/用词/时态/表达地道度"几类，让反馈可读。

### 6.2 可以绕开的（它做了但对我们价值不高 / 我们做不动）

1. **自研 ASR 与大规模语音数据库**（537 亿句录音级别）——直接调用成熟评测/识别能力或开源 GOP 方案即可，不与之正面竞争。
2. **真人外教 1V1、班主任督学、30 人小班社群**——重人力、不可规模化，且与"AI 驱动"的产品叙事冲突。
3. **正版外刊 / 原版书籍 / 影视配音内容库**——版权成本高，与口语训练主线关系弱。
4. **应试题库与机经预测（雅思/托业）**——需要长期教研与命中率验证，项目周期内做不出可信度。
5. **儿童/少儿条线（3-12 岁）**——用户画像、合规要求（未成年人保护、内容审核）完全不同。
6. **完整社交网络（关注/私信/动态流）**——流利说砍掉它并没有死，但维护成本很高；保留"打卡 + 成绩卡片分享 + 话题区"即可。
7. **原生多端 App**——Web 响应式优先的既定决策是对的，不必在项目期内投入 iOS/Android 原生开发。

### 6.3 可以打的空档（它的软肋 = 我们的机会）★ 最重要

**G1｜开放式 LLM 场景扮演，是它的范式盲区。**
它的"对话"要么是脚本化教材，要么外包给真人语伴（[App Store](https://apps.apple.com/cn/app/id597364850)）。VocalVerse 用 DeepSeek 做**角色 + 场景 + 目标 + 分支**的多轮扮演（点餐、租房、面试、会议、答辩），用户说什么系统都能接住，且能**根据用户水平动态降/升难度**。**这是它十年资产反而拖累它的地方：它的评分体系建立在"已知参考文本"之上，开放对话恰恰没有参考文本。**

**G2｜"对话中的即时纠错 + 更地道说法改写"是空白。**
它的语法检错主要面向英文文本/写作打分引擎（[AI 技术页](https://www.liulishuo.com/tech.html)），未见在口语多轮对话中实时纠错的公开证据。VocalVerse 可以做到：每轮回复后给出 ①听到的转写 ②语法错误定位 ③"母语者会这么说"的改写建议 ④本轮发音薄弱音素。**"评分 → 诊断 → 改写 → 复述"这个四步闭环，就是我们相对它最锋利的差异点。**

**G3｜模拟面试 / 答辩导师：用 AI 打它 ¥8,980 的人工私教。**
它把"英文面试、职场 Presentation、商务谈判"放在需要真人外教的高客单私教课里（[教育在线 FAQ](https://gaokao.eol.cn/gzxy/yxdt/202607/t20260701_2751474.shtml)、[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_30885166)）。VocalVerse 的「答辩导师 / 模拟面试」场景把这件事 AI 化、零边际成本化，且对高校用户（毕业答辩、留学面试、竞赛路演）是**刚需且高频**。**这是我们最容易讲清楚价值、也最容易做出 Demo 冲击力的场景。**

**G4｜英文歌跟唱（音准 + 节奏评分）是完全空白的娱乐化入口。**
流利说全线产品无此形态。VocalVerse 的「英文歌练唱」（LRC + 基频提取 + DTW 对齐 + 逐句音准/节奏评分）既是差异化特色，也解决了 W7 所指的"坚持不下去"问题——**把训练包装成娱乐，是对抗流失率的结构性方案。**

**G5｜Web 免安装 + 教学/教研场景，是它主动放弃的阵地。**
它没有 Web 学习端（[官网](https://www.liulishuo.com/)）。VocalVerse 的 Web 端可直接进机房、进课堂、进企业办公电脑，并配套运营端（用户管理、场景/歌曲库管理、评价看板），形成"学生练 + 教师看"的双端价值，这在需求答辩中是可讲的完整故事。

**G6｜信任与透明：不做预付费陷阱。**
它当前最刺眼的负面是退费条款与虚假宣传投诉（[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_30885166)）。VocalVerse 若涉及任何付费/权益设计，应把"可随时退出、数据可导出、无自动续费暗坑"写进产品规则并在 UI 中显性提示。**分析：** 在一个用户被伤害过的品类里，"透明"本身就是可感知的产品特性。

**G7｜可解释反馈：给"怎么改"，而不只是"多少分"。**
用户吐槽"有些词示例发音都不正确""不值那个价"（[豌豆荚](https://www.wandoujia.com/apps/com.liulishuo.engzo)），本质是"我拿到了分数但不知道怎么变好"。VocalVerse 应做：**音素级错误定位 → 具体口型/舌位/连读提示 → 定向 3 句训练 → 复测对比曲线**。这是低技术门槛、高感知价值的功能。

**G8｜学习数据主权与成果导出。**
把学习报告做成可导出的 PDF（能力雷达、薄弱音素清单、对话样本、提升曲线），可用于课程作业、求职材料、教师评估。它的报表锁在 App 内且服务于续费。

**G9｜"效果可验证"的产品化。**
借鉴它公布 746 人 / 36.88 小时 / 40% 提升一个欧标等级的做法（[懂你英语页](https://www.liulishuo.com/dongni.html)），VocalVerse 应在埋点模块（P1）中预留"学习时长 vs 评分提升"的统计口径，在验收/答辩时给出自己的效果曲线——**哪怕样本只有 30 人，方法论的完整性就是加分项。**

## 八、SWOT 综合评估

### Strengths（优势 · 内部）
1. **音素级多维语音评测引擎自研可控**，粒度与维度均有官方明确口径，行业内属第一梯队（[AI 技术页](https://www.liulishuo.com/tech.html)）。
2. **537 亿句 / 40 亿分钟中国人英语语音数据资产**，对中式口音鲁棒性构成难以逾越的壁垒（[关于我们](https://www.liulishuo.com/aboutus.html)）。
3. **课程体系工业化 + 国际量表对标**（8 级 / CEFR A1–C2 / CSE / 托业雅思映射 / 万级题量）。
4. **品牌与权威背书**：G20 志愿者培训、上海市级企业重点实验室、CB Insights 全球 AI 百强、苹果年度精选。
5. **完整商业闭环**：¥1 → ¥99 → ¥1996 → ¥8980 的价格阶梯与 C/B 双线变现路径。
6. **2.537 亿累计注册用户与 14.9 万 iOS 评分的存量口碑（4.45 分）**。

### Weaknesses（劣势 · 内部）
1. **交互范式落后于 LLM 时代**：无公开可核实的 AI 自由对话能力，"多轮对话"仍依赖真人语伴。
2. **口碑与合规风险显性化**：退费"两周霸王条款"被媒体与律师公开质疑，虚假宣传类投诉见诸报道（[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_30885166)）。
3. **功能删改史伤害老用户**：情景对话、私信关注、配音课等被移除引发长期抱怨（[App Store 评论](https://apps.apple.com/cn/app/id597364850)、[豌豆荚评论](https://www.wandoujia.com/apps/com.liulishuo.engzo)）。
4. **性价比争议**："课程不值那个价""示例发音不正确"，安卓渠道好评率仅 82%。
5. **端形态残缺**：无 Web 学习端，PC/课堂/机房场景缺位。
6. **基本盘持续收缩**：付费用户两年流失约 78%，三年累计亏损约 14.58 亿元，已退市私有化（[华夏时报](https://www.163.com/dy/article/HAKP4ED70512D03F.html)、[Nasdaq](https://www.nasdaq.com/press-release/laix-inc.-announces-completion-of-going-private-transaction-2022-10-11)）。

### Opportunities（机会 · 外部）
1. **大模型平权**：语音+LLM 能力已可通过 API 获取，"能否做出对话产品"不再取决于自研模型规模——对流利说是威胁，对新进入者是机会。
2. **成人职场英语刚需未被高性价比方案满足**：面试、会议、谈判等高价值场景当前主要由高客单人工服务覆盖（¥8,980 量级），AI 化空间巨大。
3. **企业/高校 B 端预算稳定**：其企业版与 G20 案例证明机构付费意愿真实存在，且对 Web 端与管理后台有天然需求。
4. **出海与多语种**：评测引擎能力可外溢至其他语种与海外华人/亚洲市场（对其而言是机会，也是我们要注意的方向）。
5. **信任修复的市场空位**：预付费消费新司法解释（2025 年 5 月 1 日施行）提高了行业合规门槛，"透明、可退、无套路"成为可差异化的卖点（[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_30885166)）。

### Threats（威胁 · 外部）
1. **LLM 原生竞品的降维打击**：以自由对话为核心的口语类应用（如多邻国、Speak、TalkAI 等）在同一应用商店搜索结果中评分普遍高于流利说（如多邻国 4.78/152 万评分、TalkAI 4.85/8.5 万评分，[App Store 搜索结果](https://apps.apple.com/cn/app/id597364850)）。
2. **通用助手替代**：ChatGPT/豆包等通用语音助手可零成本承担"陪聊 + 纠错"，蚕食其低端付费需求。
3. **免费替代内容泛滥**：用户已公开表达"音标、连读的免费教学视频一大堆"，削弱课程付费意愿（[豌豆荚](https://www.wandoujia.com/apps/com.liulishuo.engzo)）。
4. **政策与合规压力**：教培治理、微信生态对"利诱分享打卡"的封禁曾直接摧毁其增长引擎，同类风险持续存在（[华夏时报](https://www.163.com/dy/article/HAKP4ED70512D03F.html)）。
5. **人力密集模式的成本与投诉风险**：靠外教 1V1 拉高客单必然带来履约、退费与舆情风险，形成负反馈循环。

## 九、结论：对 VocalVerse 功能取舍的直接指令

**分析（综合判断）：**

1. **不要在"评分准确率"上与它竞争，要在"反馈可用性"上超越它。** 我们的评分调用成熟能力即可，胜负手在"诊断 + 改写 + 定向训练 + 复测对比"的闭环。
2. **把 P0 资源全部压在「LLM 场景扮演多轮对话 + 对话内即时纠错」上**，因为这是它范式性缺失、且我们技术上完全可达的唯一大空档。
3. **「答辩导师 / 模拟面试」应从 M2 特色功能升格为核心叙事**——它对应竞品 ¥8,980 的人工服务，价值锚点清晰、答辩演示效果最好。
4. **「英文歌练唱」保留为 P1 差异化特色**，作为留存与传播抓手，但不得挤占 P0 口语闭环的工期。
5. **入学测试必须给出 CEFR/CSE 对标结论**，报表必须包含"薄弱音素清单 + 提升曲线"，否则在专业性上会被一眼比下去。
6. **社区维持 P2 最小实现**（打卡 + 成绩卡片分享），有充分竞品证据表明重社交不是本品类的胜负手。
7. **Web 优先的技术路线是正确的且是差异点**，应在文档与答辩中明确将"无需安装、可进课堂机房、含运营管理端"作为对比优势陈述。
