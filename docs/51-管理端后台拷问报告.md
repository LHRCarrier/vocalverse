## 0. 一句话结论

**v1 设计被四路拷问判定为「不可直接实施」。** 四路共报 **33 条 P0**
（并发性能+日志 **7** / 数据模型+业务联动 **9** / 架构模块+范围取舍 **11** / 前端 UI-UX+图表 **6**），
合流去重后按 **30 项逐条裁决**（采纳 / 部分采纳 / 驳回，驳回附理由）。
其中 **8 条属于"证据确凿、可当场复现"的硬缺陷**：

1. **`0013` 迁移在真 PG 上必然失败**——而本机无 Docker、`--sql` 渲染与 SQLite `create_all` **都抓不到**；
   是离线渲染出的 DDL 字符串（`CONSTRAINT ck_media_assets_ck_media_assets_status`）把它暴露的。
2. **`aud` 声明是假的**——实现注释声称"App 侧会拒绝控制台令牌"，而既有 `JwtService`/`JwtAuthFilter`
   **既不签发也不校验 `aud`**，且控制台默认回退共享密钥 → 控制台令牌可被当作真实 App 用户身份使用。
3. **隐藏生效清单是 18 处不是 8 处**，漏掉的 10 处里**包含通知中心**——只改 `PostRepository` 时，
   隐藏帖仍会通过通知露出标题/评论正文，而 v1 的验收用例不覆盖通知 → **自测会通过**。
4. **指标分位数无处可存**——DDL 只有 `avg/max/min`，指标目录却要 p50/p95/p99；
   跨桶取平均得到的是"平均的分位数"，而 v1 自己的验收用例要求"step 聚合与直接聚合一致" → **该用例必红**。
5. **内容捕获推翻已写红线**——`docs/06 §9.7` 明写"只存评分/转写/元数据""不 log 论文/转写/请求体"，
   而 v1 只申请了两条无关的 ADR 修订，且 `redact()` 对答辩论文正文无效。
6. **依赖方向规则与埋点位置自相矛盾**——§3.1 断言"领域模块不得 import console，grep 可 CI 校验"，
   §7.3 却把埋点放进领域模块内部 → 按 §3.1 的实现会被自己的门禁判红。
7. **`TraceWaterfall` 的脚注在说谎**——脚注写"长度 = 耗时（未截断）"，代码却有 `MIN_BAR = 1.5px` 下限
   （30s trace 上 1px ≈ 110ms，20ms span 真实宽度 0.18px）。这是**我方代码**的缺陷。
8. **仓库的 `pnpm typecheck` 从未检查过任何代码**——`apps/web` 根 `tsconfig.json` 是 solution-style
   （`files: []` + references），`vue-tsc --noEmit` 零文件可查。实测：故意写入类型错误，**退出码 0**。

本报告给出逐条裁决与 **v1 → v2 修订清单**；已采纳项已回填 `docs/50` 与实现（含 7/8 两条的代码修正）。

### 1.7 退役口径修正：删的是"入口与第二套权限"，不是"产品的写入能力"

设计 v1 在 §15.5 写的退役清单**只列了删除目标，没有核对这些目标有没有替代路径**——
结果就是 I-9：内容域的增删改**没有**任何替代（工单是"有 API 没页面"，内容域更严重，是"连 API 都没有"）。

**修正后的退役原则（一句话）**：

> **删掉旧的 `/api/v1/admin/**` 入口与 `ROLE_ADMIN` 权限语义；保留能力，并把它搬到控制台权限码 + 审计之下。**

落地：`ContentAdminController` + `QuestionAdminController` 的 CRUD **不删，而是迁到 `/api/v1/console/content/**`**，
用 `content:{song,scenario,listening,question}:write` 授权、写审计；然后删掉 `/api/v1/admin/**` 的原版。
净效果仍是"旧管理端作为入口与权限体系**彻底消失**"，但**能力零回退**，且每一次写入都进审计流。

**这段经历本身是收获**：我在 `docs/50 §15.5` 亲手写下"退役后必须复核：没有控制台功能因此回退"，
然后在同一份文档里**自己违反了它**（只列删除项、没核替代路径）。教训写进 SOP：
**凡"退役/删除"清单，每一行都必须配一列"能力迁到哪"——没有这一列就不算清单。**

### 7.3 契约对齐结果（两路对齐代理，**DTO 系统性失真的完整清单**）

> **凡设计文档里的字段名，都必须在实现之后对着源码核一遍**（`docs/50 §10` 已加此口径）。
