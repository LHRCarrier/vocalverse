# 错误码表（docs/06 第 7 章）

> 登记纪律：新增错误码按 4xxxx（4 开头业务）与 5xxxx（服务）分段，先在本表登记后提交 PR（本表 = 代码全集，2026-09-07 补齐 409xx/41001/42202 与 40301 语义；2026-09-06 社区 S1 段：40402/40302/42203/40904）。

| code | HTTP | 含义 | 处理 |
|---|---|---|---|
| 0 | 200 | 成功 | - |
| 40001 | 400 | 参数错误（含音频文件名非法） | 前端提示 + 校验表单 |
| 40002 | 400 | 音频为空或过短（< min_upload_bytes） | 提示重录，不消耗题目/回合与限流额度 |
| 40101 | 401 | 未登录 / token 失效 | 前端跳登录 / 走 refresh |
| 40301 | 403 | 无权限：非 admin，**或非本资源归属**（报告/音频/会话越权即 403/404） | 提示无权限；越权场景统一按资源不存在处理，不泄露存在性 |
| 40302 | 403 | 越权：社区内容非作者（软删/仅本人可见）/ 已停用互动（如 checkin 卡投币评论） | 提示无权限；与 40402 二选一——不泄露存在性时用 40402 |
| 40401 | 404 | 资源不存在（会话过期/报告不存在/档案不存在） | 提示 + 路由回退 |
| 40402 | 404 | 社区内容/评论不存在或已删除 | 提示 + 路由回退 |
| 40901 | 409 | 会话锁冲突（多副本并发、重复提交；Redis 锁落地后启用，当前进程内锁不产生此码） | 前端提示稍后重试，不重放录音 |
| 40902 | 409 | 会话状态不允许该动作（如非 awaiting_user 时提交回合） | 前端刷新会话状态 |
| 40903 | 409 | stale turn（expected_turn 与服务端不一致） | 前端采纳服务端权威轮次（目标态：turn_start/turn_end 回带 next_expected_turn） |
| 40904 | 409 | 社区重复表态冲突（投币已投/分享已计——唯一键兜底） | 幂等返回当前态，不双计、不报错 |
| 41001 | 410 | 音频已过期（24h 惰性清理，超 TTL 即删） | 提示重录；服务端对已删文件保留 410 语义防枚举 |
| 41301 | 413 | 音频超过 20MB | 前端压缩或分段 |
| 42201 | 422 | 请求体校验失败 | 展示字段级错误 |
| 42202 | 422 | 该 action 需要音频（normal 回合缺音频） | 提示重录 |
| 42203 | 422 | 社区入参非法（kind/domain 枚举、body/title/评论长度、发帖开关关闭=409 语义用 40302 而非本码） | 展示字段级错误 |
| 42204 | 422 | 录音过长（对话轮 > max_dialog_seconds；vasr-05 时长校验） | 提示缩短后再试，不扣额度 |
| 42901 | 429 | 触发限流 | 展示 Retry-After 秒数 |
| 50001 | 500 | 上游服务超时（LLM/评分） | 重试或降级提示 |
| 50301 | 503 | ASR/TTS 服务不可用 | 提示稍后再试（demo 预合成保底） |
| 50302 | 503 | 数据库/缓存不可用 | 提示维护中 |
