# 错误码表（docs/06 第 7 章）

> 登记纪律：新增错误码按 4xxxx（4 开头业务）与 5xxxx（服务）分段，先在本表登记后提交 PR（本表 = 代码全集，2026-09-07 补齐 409xx/41001/42202 与 40301 语义；2026-09-06 社区 S1 段：40402/40302/42203/40904；2026-09-09 社区 S3 媒体段：40403/41501/42205 + 拓宽 41301；**2026-09-10 管理端控制台段：46001~46015**，见 docs/50 §10.4 与 docs/51 裁决表）。

| code | HTTP | 含义 | 处理 |

| 0 | 200 | 成功 | - |

### 管理端控制台段 `46xxx`（docs/50 §10.4 · 2026-09-10）

> 独立段位理由：控制台是**独立身份体系**（`admin_users`，与 `users` 无关联），其 401/403 语义与 App 的 40101/40301 不同——
> 复用会让前端无法区分"App 登录过期（跳 App 登录页）"与"控制台登录过期（跳控制台登录页）"。
> **带结构化 `data` 的码见 `envelope.md`「错误 data 的结构化例外」**（46002/46003/46008/46011/46015），其余 `data` 恒 `null`。

| code | HTTP | 含义 | 处理 |
|---|---|---|---|
| 46001 | 401 | 管理端未登录 / 控制台令牌失效 | 跳**控制台**登录页（不是 App 登录页） |
| 46002 | 403 | 管理端权限不足（缺具体权限码；`data.required` 回传所需码） | 展示所需权限码，引导找超级管理员开权限 |
| 46003 | 403 | 管理端账号已停用 / 已锁定（`data.lockedUntil`） | 提示停用或锁定到期时间，**不要反复重试**（会延长锁定） |
| 46004 | 404 | 管理端账号不存在 | 刷新列表 |
| 46005 | 409 | 管理端用户名已存在 | 换用户名 |
| 46006 | 409 | 角色不可删除（内置角色 / 仍有成员 / 仍被引用） | 先移出成员或改用停用 |
| 46007 | 422 | 管理端入参非法（枚举/长度/时间窗过大；时间窗超限时 `data.suggestedStep` 回传建议 step） | 按提示收窄查询 |
| 46008 | 429 | 管理端登录失败次数过多（`data.retryAfter` 秒） | 等待或联系超级管理员解锁 |
| 46009 | 404 | 审核对象不存在（内容已物理消失） | 刷新队列 |
| 46010 | 409 | 审核单状态不允许该动作（已终态 / 并发下已被他人处理） | **这是预期的并发结果**，刷新后重取 |
| 46011 | 422 | 上架校验失败（`data.violations[]` 字段级原因，**形状 `{field, code, message}`**，见 `envelope.md`） | 按字段列表补齐元数据后重试 |
| 46012 | 404 | LLM trace 不存在或已过保留期（默认 30 天） | 调整时间范围 |
| 46013 | 503 | 遥测存储不可用（采集/查询降级；**业务不受影响**） | 提示运维通道降级，不是服务故障 |
| 46014 | 403 | 运维采集通道未开启（`APP_OPS_TELEMETRY_ENABLED=false`） | 需要看指标时开启该开关并重启 Python 服务 |
| 46015 | 409 | 举报已存在待处理记录（`data.caseId` 回传既有审核单） | 直接跳转既有审核单，不重复建单 |
