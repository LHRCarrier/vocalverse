## 3. 写归属矩阵（Single Writer，核心约定）

### 3.1 总表

| 写方 | 拥有的表（唯一 DB 写权） | 只读 | 说明 |
|---|---|---|---|
| **Java** | users / user_profiles / refresh_tokens / scenarios / songs / lrc / listening_materials / placement_questions / tickets | placements / sessions / scenario_messages / attempts / sing_attempts / post_likes / events / reports | 管理端 CRUD + JWT 签发 + 题库；**不做任何 DDL**（`ddl-auto=none`） |
| **Python** | placements / sessions / scenario_messages / attempts / scores / sing_attempts / song_pitch_refs / post_likes / events / reports | users / user_profiles / scenarios / songs / lrc / listening_materials / placement_questions / tickets | 语音/评分/LLM/推荐/埋点落库/聚合报表/社区点赞 |

### 3.2 交叉写点的处理（最重要的三条细则）

1. **入学测试档位回写（placements → user_profiles.cefr_level）**
   - 流程：Python 算出入学综合分 S 与档位 → 写 `placements`（自己拥有）→ **调用 Java 内部接口** `POST /internal/profiles/{user_id}/level`（`X-Service-Token` 头，非热路径、3s 超时）→ Java 更新 `user_profiles`。
   - 失败降级：内部调用失败**不阻塞**入学测试完成（日志告警，profile 档位保持旧值）；Java 侧看板/管理页可直接读 `placements` 最新 completed 记录校对。**禁止 Python 直写 user_profiles**。
2. **参考旋律提取（lrc → song_pitch_refs）**
   - `song_pitch_refs` 是 Python 拥有的次生表，以 `lrc_id` 外键 + `ON DELETE CASCADE` 挂接 Java 内容库：LRC 改动（Java 侧整首重写）→ 旧行级联删除 → Python 离线任务检测缺失并重提取。**songs/lrc 表本身 Java 独占**，Python 不写。
3. **报表数据流（events → reports）**
   - Python 独占 `events`（埋点落库）与 `reports`（按口径聚合）；Java「评价看板」只读 `reports`——Java 侧**不实现任何指标口径**（口径公式唯一归 Python，见 docs/06 §9.1）。

### 3.3 只读方的读取约束

- Python 读 `users`/`user_profiles`：验签后取档位/年龄组（只 SELECT，不缓存超过 30min 的画像——防「刚改档位推荐还按旧档」）。
- Java 读练习域：报表/管理页，全部走只读 JPA 映射 + 只读事务（`@Transactional(readOnly=true)`）。
- 禁止「读方」为绕过写方而做本服务内的落库副本（出现即违反 P8，评审直接打回）。

## 4. 逐表字段设计（模型代码为准，此处为决策记录）

### 4.1 账户域（Java 写 → Python 只读）

**users**
| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT IDENTITY PK | 显式 ID 插入合法（种子数据用） |
| username | VARCHAR(64) NOT NULL | 唯一性由 `lower(username)` 表达式唯一索引保证（大小写不敏感） |
| email | VARCHAR(254) NULL | 同样 lower() 唯一；可空（无强制邮箱策略） |
| password_hash | VARCHAR(255) NOT NULL | BCrypt（Java 侧 Spring Security） |
| nickname | VARCHAR(64) NOT NULL | 成绩卡片展示名（docs/07 Q26） |
| role | VARCHAR(16) DEFAULT 'user' | CHECK ('user','admin') |
| status | VARCHAR(16) DEFAULT 'active' | CHECK ('active','disabled')；**禁用不删除** |

**user_profiles**（1:1 users，注册时 Java 建行并按下表默认值初始化）
- `age_group`（child/teen/adult/senior，默认 adult）→ 只驱动 TTS 语速/音色/默认难度（docs/06 §9.2），不参与内容过滤；
- `cefr_level`（L1~L4）＝最近一次 completed placements 的快照（经 §3.2-1 委托回写）；
- `interest_tags` JSONB []（推荐兴趣标签）；`learning_goal` VARCHAR(255)；
- `voice_rate`（slow/normal/fast）+ `voice_type`（3 音色预设 key，字符串不 CHECK——预设表放配置，schema 不锁死）；
- `preferred_difficulty` SMALLINT NULL CHECK 1..4（默认按 age 预选，设置页可改）；
- `avatar_url` VARCHAR(512)。

**placements**（Python 写）
- `exam_revision` SMALLINT DEFAULT 1：固定朗读题版本（docs/06 §9.2 可复现）；
- `status`（in_progress/completed/abandoned）：独立状态机，**不复用 sessions**（避免两个状态源，见 §6 开放项 B-2）；
- `overall/pron/flu/gram_score` NUMERIC(5,2) NULL + `level`（S 按配置阈值折算，快照）；
- `details` JSONB：每题明细 [{item_index, transcript, scores, errors}]；
- 判定公式 S=0.4·发音+0.3·语法+0.3·流利度（docs/06 §9.2）不落库、放 Python 配置。

**refresh_tokens**（Java 写）
- `token_hash` CHAR(64)（SHA-256，**不存明文**）；`expires_at`/`revoked_at`（rotation：刷新=旧行置 revoked）；
- `user_agent`/`ip`（审计用，登录时快照）；多设备策略见 §6 开放项 A-2。

### 4.2 内容域

**scenarios**（Java 写）
- `scene_type` CHECK ('cafe','airport','interview','library','other')（docs/06 §9.6 定稿 4+1 兜底）；
- `system_prompt`（角色设定）/`opening_line`（开场白）/`target_corpus`（目标语料）；`difficulty` SMALLINT CHECK 1..4；
- `prompt_version` SMALLINT DEFAULT 1：**改 prompt 必须 +1 不覆盖**（消息流水按版本快照解释行为）；
- `interest_tags` JSONB；`status` draft/published/archived；索引 (status,difficulty)。

**songs**（Java 写）
- `level` 1..4；`bpm`/`musical_key`（节奏粗校准参考，实际以 song_pitch_refs 为准）；`audio_url` NOT NULL；
- `source` CHECK ('public_domain','original','demo_only')——**商用音乐严禁入库**（docs/06 §9.7）；
- `lrc_url` 仅存原始文件引用（可选）；逐句数据唯一真源 = `lrc` 表。

**lrc**（Java 写）
- `(song_id, seq)` 唯一；`offset_ms` NOT NULL（句起点）；`end_offset_ms` NULL（⚠️ 补充字段：docs/06 §10 只列 offset/text/seq；end 用于逐句评分窗口，若 Java 侧不维护可空，算法按下一句 offset 推断）；
- `text`；编辑方式＝整首重写（删旧插新），触发 song_pitch_refs 级联重建。

**song_pitch_refs**（Python 写，⚠️ 补充表）
- `lrc_id` FK CASCADE（LRC 改 → 级联清 → 离线重提取）；`(start_ms,end_ms)` 句窗口；
- `pitch_ref` JSONB {"f0s":[...], "notes":[...]}；`extractor`(默认 pyin)/`version`（算法可追溯，同曲重提取后旧分数可解释）。

**listening_materials**（Java 写，⚠️ 补充表）
- title/level/audio_url/transcript（ASR 字幕示例）/interest_tags/status；推荐候选池第三类（docs/06 §9.5）。

### 4.3 练习域（全部 Python 写）

**sessions**
- `kind` CHECK ('dialog','sing')；`status` active/completed/abandoned；
- `scenario_id`/`song_id` FK **SET NULL**（内容归档不影响历史）；`started_at`/`completed_at`；`turn_count`（会话关闭时快照）、`duration_s`；
- **只存事实，不存口径**：完成率（5 轮或 2min / 整首逐句结束）在 reports 层按 re-play 计算，口径改动不用迁数据；
- `channel`（web/…）默认 'web'。

**scenario_messages**（不可变，只 INSERT）
- `(session_id, seq)` 唯一；`role` system/user/assistant；
- `origin`（'proactive'/'respond'，仅 user 行）→ **互动率分子分母的前提**（docs/06 §9.1）；
- `action`（'demo'/'correction'/'retry' NULL）→ 功能互动补充指标（点示范/纠错/二次录制）；

- `audio_url`/`duration_ms`：该轮录音引用（原始音频默认 24h 清理，字段保留为 NULL 或失效链接，见 §6 开放项 E-1）。

**attempts**
- `kind` dialog_speech/free_practice/placement_item；一次录音一条 **评分快照**；
- 得分字段一律 NULL 允许：管线降级/失败落 `error` JSONB，不伪造分数；
- `transcript` 仅文本；`details` JSONB 词级错误 [{word, word_index, error_type, suggestion, demo_audio_url}]（ADR 9.3 默认单词级）；`wpm` 语速辅助（docs/07 Q21 附加指标）；
- `completeness` 预留（语法项若被砍，口径改发音/流利度/完整度时用，docs/06 §9.3）。

**scores**（音素级明细，仅重难点词）
- `(attempt_id, word_index, phoneme)` 唯一；`start_ms/end_ms` 锚点；`error_type` CHECK（替换/省略/插入/错读/重音/语调/其他）；`is_key_word` 触发音素提示 + TTS 示范；`attempt_id` FK CASCADE。

**sing_attempts**
- 一首歌一条：`overall = 0.5·pitch + 0.2·rhythm + 0.3·pron`（公式在 Python 配置，不落库）；
- `lines` JSONB 逐句 [{seq, start_ms/res, pitch_score, rhythm_score, pron_score, synced, skipped}]；

**events**（只追加）

## 5. 写归属契约的细则（写方必须遵守）

1. **更新必须维护 updated_at**：SQLAlchemy `onupdate=func.now()` 只对 Python 侧 UPDATE 生效；Java 写方用 `@LastModifiedDate` 或显式赋值，与 Python 侧保持一致（见 4.x 各表 updated_at）。
2. **JSONB 字段**：写方落库前必须序列化为 `list/dict`（SQLAlchemy 自动处理）；Java 侧映射为 `String`+`JsonNode`（validation），**不要** 用 Hibernate `@JdbcTypeCode(SqlTypes.JSON)` 以外的注解去假设表结构。
3. **分数一致性**：attempts/sing_attempts 的明细分与总分都在同一事务写入；单条流水线失败时写 `error` 快照后**不写分数行**（分数 NULL）。
4. **事件幂等**：Python 侧 INSERT events 前先按 `client_event_id` 查重（唯一索引兜底并发）；重复到达返回 ok（不报错、不重复计）。
5. **内容下架**：Java 侧只置 `status='archived'`，不删行；`songs.audio_url` 指向的文件删除与元数据标记由 Java 侧负责（入库红线下，文件在卷上不进 git）。
6. **清理任务**（Python）：原始音频 24h TTL 清理只删文件；DB 行保留（metadata 无 PII），audio_url 字段保留原值（被清理时由清理任务统一在事件/日志说明）。⚠️ 待拷问确认（§6 E-1）。

## 7. Alembic 迁移规范（管表结构演进的唯一工具）

### 7.1 工作流

1. **改模型 → 本地起 PG（`docker compose up -d postgres`）→ `alembic revision --autogenerate -m "<语义>"` → 人工审阅 → `alembic upgrade head` → `alembic check`（必须零 diff）→ 连测**。
2. **一个 PR 一个迁移**；迁移文件内不得夹带业务代码/数据（纯 DDL；seed 见 7.3）。
3. **已合入的迁移禁止修改**（含 down_revision 链）；修错 = 新迁移。
4. 迁移生成后**必须人工 review autogenerate 输出**——禁无条件信任（本首迁移修了 4 类：表达式索引漏出/默认值归一/JSONB 渲染 Text/文档头；docs/11 Q-A04~A06/A18）。
5. naming_convention（`app/models/base.py`）：PK/FK/UQ/CK/IX 名全部确定性生成——保证 check 稳定、可复现。
6. **M2 接 PG 首日必做**：`alembic upgrade head && alembic check`（零 diff 门禁）+ 把 python-ci 升级为「单头（`-eq 1`）+ 带库零 diff」双探针（docs/11 Q-A10/A11）。若 with_variant/表达式索引出噪音 diff，按 Q-A04/Q-A05 的处置预案走（自定义比较器或规范化模型类型）。

### 7.2 env.py 关键开关（已配置）

| 开关 | 值 | 理由 |
|---|---|---|
| target_metadata | `app.models.Base.metadata` | 19 表全量注册 |
| compare_type | True | 字段类型漂移必查 |
| compare_server_default | **自定义比较器** `_compare_server_default` | 过滤两类已知噪音（`::jsonb` 后缀、now()/CURRENT_TIMESTAMP），其余默认值漂移照常报警（docs/11 Q-A06：不做整体关闭） |
| render_as_batch | True | SQLite 下 ALTER 走 batch（保险） |
| 连接串 | `APP_DATABASE_URL` env 优先（与 pydantic settings 同源） | **禁止再出现裸 DATABASE_URL**（docs/11 Q-A03：双名分裂导致 app 连 SQLite、迁移跑 PG）；alembic.ini 保持纯 ASCII（GBK locale Windows 会炸，实测） |

### 7.3 种子数据（seed）

- 规则：`alembic` 只做 DDL；**幂等 seed** 放 `services/python/app/db/seed.py`（Python 侧执行脚本），demo 内容（3 画像用户、4 场景、公有领域歌曲、题库、LRC/歌）由 seed 脚本写入。
- **users 表写归属=Java**：seed 属开发期数据初始化器，与运行时「单写方」契约并存，需组长拍板二选一：① seed 豁免单写（默认，成本最低）② 用户种子改 Java `CommandLineRunner`（严格单写）。拍板前 seed 不得对帐号表写入（docs/11 Q-A15）。
- **IDENTITY 序列纪律（docs/11 Q-A01，P0）**：种子一律**不写显式 id**（由 DB 生成后 `lastval()` 关联）；确需显式 ID 时必须在脚本尾部推进序列：`SELECT setval(pg_get_serial_sequence('users','id'), (SELECT max(id) FROM users))`——否则后续注册的首个用户必然 PK 冲突。`ON CONFLICT DO NOTHING` 只保证幂等、不解决序列。
- seed 中密码哈希必须与 Java BCrypt 完全一致（同库同 cost；`$2a`/`$2b` 前缀一致性），否则演示登录失败（docs/11 Q-A15）。

## 8. Java 侧映射注意（写方/读方通用）

| 模型侧 | Java JPA 侧 |
|---|---|
| BIGINT IDENTITY | `@Id @GeneratedValue(strategy = IDENTITY)` Long |
| VARCHAR+CHECK 枚举 | `@Enumerated(EnumType.STRING)` 或 String + 常量校验 |
| JSONB | `@JdbcTypeCode(SqlTypes.JSON)` String/JsonNode（**读侧**）或对应 DTO |
| timestamptz | `OffsetDateTime`（推荐）或 `Instant`（应用层转 UTC） |
| NUMERIC(5,2) 分数 | `BigDecimal`（精度敏感，勿用 double） |
| 表达式唯一索引 | JPA 无法表达，**只读场景不建索引注解**（表已由 Alembic 创建） |
