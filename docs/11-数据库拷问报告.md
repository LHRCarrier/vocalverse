## A. schema-迁移工程官拷问（Q-A 系列）

> 拷问官总结：逐字段核对 17（今 19）张表模型与迁移**完全一致**（唯一差异是刻意重映射的时间戳默认值与 JSONB 书写的 astext_type 差异，均非功能性错误）；FK 顺序/downgrade 逆序/单头线性均正确。真正风险集中在：**autogenerate 可重复性**（with_variant + 表达式索引在 PG 反射比对下是噪音 diff 高危区，且 alembic check 尚未进 CI——漂移窗口期无机器守护）+ 4 个会在运行时/演示期爆的真雷（种子 ID 序列 / Decimal / URL 双名 / CI 假绿），另加 1 个设计者自查新雷（Lrc 属性名遮蔽 text()）。

### A.1 P0（必改，1 条）

**Q-A01（P0）种子显式 ID 插入会让 IDENTITY 序列不前进，后续注册直接 PK 冲突。**
- 为什么重要：`GENERATED BY DEFAULT AS IDENTITY` 在显式插 id 时不推进底层序列；seed 写 id=1/2/3 后注册首个用户拿到 id=1 → 演示期必炸。
- 处置：✅ **已写入 docs/10 §7.3 契约**（seed 不写显式 ID 用 lastval() 关联；确需显式 ID 必须 `setval(pg_get_serial_sequence(...))` 推进；ON CONFLICT DO NOTHING 不解决序列）。seed.py 属 M2 实现，契约已生效。

## B. 业务域-写归属官拷问（Q-B 系列）

> 拷问官总结：17 表设计在「写归属 Single-Writer」骨架与 Alembic 工程化上自洽，但**四指标口径的可计算性普遍悬空**（CTR/跳出率缺「浏览会话」关联键、唱歌「整首结束」无判定存储、互动率分母无字段）；三大疑点结论——**题库=必建表**、**模拟行为矩阵=不建表放文件**、**社区=建 1 张 post_likes**。

### B.1 P0（必改，3 条）

**Q-B01（P0）events 无「浏览/访问会话」键且无 impression→click 关联键 → CTR 不可计算。**
- 为什么重要：CTR=推荐内容被点击会话数(去重)/曝光会话数(去重)，窗口=曝光后 30min；`recommend_impression` 与 `recommend_click` 之间无可 join 标识，去重单元无法落位（recommend 事件多发生在发现页，`session_id` 常为 NULL）。
- 证据：docs/06 §9.1；docs/07 Q10；`analytics.py` events。
- 推荐处置：events 增加 `browse_session_id CHAR(36) NULL`（前端每次 App 访问生成，贯穿 page_view/impression/click，作「会话」去重键，与训练 session_id 正交）+ `recommend_group_id CHAR(36) NULL`（每次推荐流渲染生成，impression 与 click 共享，用于关联 30min 窗口）。Python 写、只追加；指标按 occurred_at 窗口 + browse_session_id 去重重算。

**Q-B02（P0）唱歌「整首逐句评分结束」无判定依据 → sing 完成率不可计算。**
- 为什么重要：完成率对唱歌=整首逐句评分结束，`sing_attempts` 仅有逐句 `lines` JSONB 与 alignment，无「是否全句已评分/应评句数」，且 lrc 会变，历史 re-play 无锚点。
- 推荐处置：`sing_attempts` 增加 `is_complete BOOLEAN NOT NULL DEFAULT false` 与 `expected_lines SMALLINT NULL`（评分时 lrc 行数快照）；`lines[]` 每项加 `ref_seq`（指向评分时 lrc 的 seq）。完成判定=`is_complete=true` 且 scored 且 skipped=false 的 count==expected_lines。

**Q-B06（P0）入学测试题库无表 → 5 条固定朗读句 + 1 轮 QA 无处存储、exam_revision 悬空。**
- 为什么重要：docs/06 §9.2「admin 题库预置，保证可复现」；schema 只有 placements（结果），无题库来源与版本 referent。
- 推荐处置：**建表 `placement_questions`**：`id BIGINT IDENTITY PK / exam_revision SMALLINT NOT NULL / item_index SMALLINT NOT NULL / kind VARCHAR(16) CHECK('read','qa') / prompt TEXT NOT NULL / reference_answer TEXT NULL / order_num SMALLINT NOT NULL / status DEFAULT 'published'`，UNIQUE(exam_revision, item_index)；**Java 写**（admin 题库），Python 读；placements.exam_revision 指向本表版本号；QA 判定结果落 placements.details JSONB。

### B.2 P1（应该改，9 条）

**Q-B03（P1）sessions.turn_count 语义（"含系统消息总轮"）与「5 轮」口径（=用户轮数）不一致 → 完成率/互动率端口径错位。**
- 推荐处置：sessions 增加 `user_turn_count SMALLINT NOT NULL DEFAULT 0`（=role='user' 消息数），完成率/互动率分母一律以此为准；turn_count 保留为总消息数（审计）。

**Q-B04（P1）互动率分母「会话分配轮数」无存储；scenario_messages.origin 可空且未约束仅 user 行。**
- 推荐处置：sessions 增加 `assigned_turns SMALLINT NULL`（会话开始时按场景配置/LLM 目标写入）；`scenario_messages` CHECK 收紧为 `(role='user') OR origin IS NULL` + `origin IN ('proactive','respond')`（仅 user 行可带 origin）。

**Q-B05（P1）跳出率「进入场景/歌曲页」无结构化入口事件、无浏览会话键。**
- 推荐处置：events 增加 `page VARCHAR(64) NULL`、`target_type VARCHAR(16) NULL CHECK('scene','song','home')`、`target_id BIGINT NULL`；跳出率=[进入 scene/song 页的 browse_session 30s 内无 recording_start/play/click]/[进入数]（与 Q-B01 browse_session_id 共用）。

**Q-B07（P1）placements→user_profiles.cefr_level 委托无对账机制；「管理员改档 vs 入学覆盖」无版本区分。**
- 推荐处置：user_profiles 增加 `cefr_level_source VARCHAR(16) NOT NULL DEFAULT 'manual' CHECK('placement','manual')` + `cefr_level_at timestamptz NULL`；Java 内部端点改幂等 PUT；补对账规则——Python 读 profile 前若发现 latest completed placement.completed_at > cefr_level_at 则触发一次重试委托（3s 超时外异步）。

**Q-B08（P1）attempts.transcript/duration_s NOT NULL 与「降级写 error 快照、分数 NULL」矛盾（ASR 失败无法 INSERT）。**
- 推荐处置：`attempts.transcript` → NULL 允许；`duration_s` → NULL 允许；失败路径 INSERT 一行（user_id、kind、error={...}，其余 NULL）。

**Q-B09（P1）attempts(transcript) 与 scenario_messages(content) 职责重叠且无绑定；重录/改轮文案时映射崩坏。**
- 推荐处置：attempts 增加 `scenario_message_id BIGINT NULL FK→scenario_messages(id) ON DELETE SET NULL` + 索引；明确 scenario_messages.content=该轮定稿文本、attempts.transcript=评分用 ASR 原文，二者可不同，靠外键对齐。

**Q-B10（P1）sing_attempts 与 song_pitch_refs/lrc 逐句无 src 引用；歌词缺失句/无参考句无表达。**
- 推荐处置：sing_attempts 增加 `lrc_id BIGINT NULL FK→lrc(id)`（评分时 LRC 版本）；lines[] 每项增加 `ref_seq SMALLINT` 与 `no_ref BOOL`；pitch_ref 缺失句标 `no_ref=true`（不判 skipped、不计完成）。
