## 3. 任务分解（PR × 子任务 × 门禁）

### P1 · 模型 + 契约（组长）
1. 契约冻结 5 项登记（§2）；
2. 迁移 0007：posts / post_comments / post_likes（重建，0 行断言 `as_sql`）/ post_interactions / follows + `user_profiles.handle/tint` + 索引（feed 双索引 + 部分唯一双方言 + uq 各表）+ CHECK（kind/domain/action/自关注）+ 软删 status CHECK；
3. `models/community.py` 只读映射（4 新表）+ `practice.py::PostLike` 按新键重写 → `alembic check` 零 diff；
4. Java 实体（`ddl-auto=none`、JSONB→JsonNode、枚举约束）+ Repository + Service/Controller（10 op）；
5. 核心事务：统一可见谓词常量（`status='visible'` 一处定义）+ like toggle（删行+同事务 GREATEST 计数）+ coin 仅 PUT（唯一键兜底）+ share 幂等 + checkin 卡互动受限（403）+ comment_count 口径；
6. CommunitySeeder：虚构作者（handle/tint/cefr_level）+ 8 条内容帖（slug/标题/摘要全原创）+ **2 条历史打卡卡**（隔日，演示混排；由种子直插 posts）→ `VOICEVERSE_SEED_DEMO` 开关；发帖开关 `VOICEVERSE_COMMUNITY_POST_ENABLED`（默认 false + 注释「生产禁止开启」）；
7. M-2 探针矩阵更新（脚本 + 豁免清单：仅 `models/community.py` 读映射例外）；
8. 测试：H2 单测（鉴权负例/软删归属/游标多取一边界/幂等双计/checkin 互动 403/可见谓词）+ PG Testcontainers（uq_posts_checkin + 每日一卡 upsert 三种分支）+ EXPLAIN 断言 + ContractSnapshotTest。

**门禁**：pytest 全量（含 alembic check）+ `mvn verify` 绿 + `pnpm gen:api` 后 typecheck 绿。

### P2 · 打卡内部委托（组长）
1. `app/core/internal_client.py`：httpx 3s + `raise_for_status()` + camelCase 体 + 结构化告警日志；**顺带修放置页 P0-6**（`_callback_level`：`user_id`→`userId` + 不再静默吞错）；
2. `complete_session` 触发（report commit 成功后，与 `_post_session_skills` 同处）+ 本会话幂等短路（已发 → 跳过）；
3. 契约/测试：docs/21 §5 登记 + respx 断言（键名 camelCase / 3s 超时 / 非 200 抛错）+ 触发点单测（收尾成功调一次；Java 不可达不阻塞收尾）。
**门禁**：pytest 全量绿。

### P3 · 前端接流（组长 · 基于已完成 mobile UI 续作）
1. `pnpm gen:api` 刷新生成类型 → `api/community.ts`（JAVA_BASE；**kind/domain 集中映射**：article/video/checkin ↔ 展示文案、news→新闻稿…、「为你推荐」空参含 NULL）；
2. `stores/community.ts`：游标分页 + 下拉刷新 + 「X 条新帖」提示条 + 滚动位置保持 + **乐观更新与失败回滚**（点赞/支持/评论成功后按后端返回计数对齐）；
3. `MobileHomeView`：换真实数据源（loading/空态分支启用）+ **独立打卡卡组件**（overall + 今日次数 + 日期 mark，仅点赞）；
4. `MobilePostActions`：投币 → **「支持/充电」+ 不可取消态**（文案+交互改造）；`MobilePostMedia`：duration 秒→时间串、视频卡点击给「视频播放 M3 上线」反馈、onerror 降级渐变；`MobileCommentsSheet`：接接口 + maxlength 对齐 500 + 后端 total 为准；
5. `MobileComposeView`：接 POST /posts（纯文本），图片/视频/话题/表情按钮置灰「未接入」；`MobileNotificationsView`：三 tab 标注「演示」（S2 接真实，mergeKey 登记）；
6. `types/community.ts` 对齐（kind 真源删 'post'/domain 可空/duration_s/checkin 字段）+ 删除 `data/community-demo.ts`（**先改 65 个既有测试对 demo 数据的引用，再删文件**——P3 门禁含「全部既有测试同步更新」）；
7. 联调预览页 `views/preview/CommunityPreview.vue` + registry + router 三行（dev-only；后端**无** test-only 开关——例外登记 docs/13 §8，验收后删除）。

**门禁**：`pnpm lint && pnpm typecheck && pnpm test:run && pnpm build` 全绿 + Playwright 冒烟（mock 鉴权 → feed 骨架/空态/列表/打卡卡）。

### P4 · 文档登记（组长，P1~P3 合入后）
§8 时序表全量 + docs/37 标定稿已完成 + 工作日志（主线 1 条：后端/契约/迁移/拷问/计划；安卓日志 1 条：前端接流 UI 部分——按 2026-09-08 定规拆分）。
**门禁**：三端 CI 复查全绿 + 契约快照 diff 复查。
