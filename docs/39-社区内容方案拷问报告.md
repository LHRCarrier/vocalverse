## 2. 分官结论摘要

- **A（需求/产品）**：核心命门 = 产品意图 ↔ UI 事实 ↔ 数据模型三处未对齐。P0 ×6：① 发帖无标题 vs 卡片必渲染标题（A-01）；② domain 中文展示 vs 英文存储映射缺失（A-03）；③ 打卡「每日一卡刷新」vs「每次进步展示」（A-06）；④ 投币=免费可取消计数器 vs 打赏心智（A-10）；⑤ 公开仓库注册即发帖无审核/限流（A-15）；⑥ 种子作者 handle/tint/LV 数据源未定（A-14）。另有答辩口径（A-17）、复用带病内部客户端（A-18）、写方守护未同步（A-19）等 P1。
- **B（技术/架构）**：P0 ×6——checkin 契约 snake_case 复刻 P0-6 bug（B-02）、错误码 40101 撞车（B-03）、keyset 分页 vs PageView 契约冲突（B-04）、feed 索引形状错配（B-05）、users.handle/tint 漏出 §3 且 slug 列不存在（B-06）、checkin 触发点散落（B-07）；B-10 静默吞错实为 P0。P1 含限流缺失、计数取消/同事务、防 N+1、media.url 白名单、M-1/M-2 未同步、H2 假绿。
- **C（数据/合规/运维）**：P0 ×2——新表必须进 Python metadata 否则 `alembic check` 必爆（C-01）、错误码撞车（C-11）。P1：离线渲染与 0 行断言冲突（C-02）、部分唯一索引双方言与 JPA upsert（C-03）、混合流索引（C-04）、计数并发/软删互动留白（C-05）、media 字段命名（C-06）、种子真实品牌版权（C-07）、打卡子分公开隐私（C-08）、media.url 注入（C-09）、限流（C-12）、slug/handle/tint（C-13）、H2 假绿（C-14）、复用坏客户端（C-15）、fire-and-forget（C-17）、follows/评论边界（C-18）。
- **D（企业融合）**：多数企业做法应「简化/后置」而非照搬。照搬 ×3：统一可见谓词、游标多取一、评论 rootId 拉平预热；简化 ×7：媒体 jsonb 占位+字段对齐、单 status、计数原子自增+唯一键删行、动作维度限流仅登记参数（Java 无 Redis 客户端）、发帖纯文本（media 字段悖论）、乐观更新+回滚、不做清单显式登记；后置：Media 状态机/通知 mergeKey/云转码/分片上传/ES。反借鉴清单见 §6。

## 3. 交叉冲突与裁决（E 官 cross_matrix · 11 项）

| # | 冲突 | 裁决 |
|---|---|---|
| 1 | keyset(next_cursor/has_more) vs envelope offset(total/page)；A-04「评论计数=列表 total」 | feed/评论用 keyset `{items,next_cursor,has_more}`（limit+1 判 hasMore）；comment_count=DB COUNT 独立于分页 total；envelope.md 登记游标例外 |
| 2 | 投币取消 vs 不可取消；share 一人一次 | coin 一人一帖一次、**不可取消**（删 DELETE /coins），文案「支持/充电」，无积分账户；like 才 toggle |
| 3 | 发帖 media 字段保留 vs 移除 | POST /posts 仅 title/body/kind/domain；media 只由视频卡/种子提供；compose 工具按钮置灰 |
| 4 | duration varchar(32)+gradient/label vs 存秒+字段对齐 | media jsonb={type,url,coverUrl,duration_s,size,mimeType,sort}；gradient/label 移前端；状态机 S2 |
| 5 | checkin 身份头 X-Service-Token vs 代码 Authorization: Bearer | ▶ 主代理修正：维持 `Authorization: Bearer <service-token>`（与 SecurityConfig 一致），docs/21 §4 R-17 同步改为代码口径（避免动安全链） |
| 6 | feed 索引 (kind,domain,…) vs 需 status 前缀 | (status,created_at desc,id desc) + (status,domain,created_at desc,id desc)，EXPLAIN 断言 |
| 7 | 错误码 40101 占用 | 40402(帖子不存在)/40302(越权软删)/42203(参数非法)，先登记后用 |
| 8 | handle/tint 落 users vs user_profiles；slug 不存在 | handle/tint 入 **user_profiles**；LV=cefr_level 派生；种子幂等键=(author_id,title)（checkin 用 (author_id,checkin_date)） |
| 9 | 限流 Java 进程内桶+Redis vs 仅登记参数 | 登记参数（发帖 5/分、点赞 30/分、投币 10/分）+ Java 轻量进程内桶（不引 Redis），Redis 桶 P1 |
| 10 | 新表入 Python metadata vs 「Python 不 import 社区模型」 | models/community.py 注册新表**只读**（供 alembic metadata），严禁写；M-2 探针仍拦 Python 写社区表 |
| 11 | LV 徽章 cefr_level vs 前端 XP LV | 社区卡 LV=user_profiles.cefr_level(L1→LV1…L4→LV4)；XP 等级为独立演示概念**不接入**社区，防双 LV |

## 4. P0 必改清单（9 项）

1. **分页契约**：feed/评论 keyset 响应 + envelope 游标例外登记；
2. **checkin 客户端**：新建统一 internal client（camelCase + raise_for_status + 3s 超时），禁止复用带病 `placement._callback_level`（顺带修 docs/21 P0-6）；
3. **错误码**：40402/40302/42203 先登记后用；
4. **feed 索引**：status 前缀双索引 + EXPLAIN 断言；
5. **users/user_profiles 补列**：user_profiles.handle/tint（迁移 0007），LV 源=cefr_level，种子幂等键 (author_id,title)；
6. **投币语义**：不可取消、一人一帖一次、文案「支持/充电」；
7. **打卡卡**：当日聚合卡（总分+次数+最佳分，公开面收敛 {overall, practice_count}）；
8. **发帖收口**：POST 纯文本；公众发帖默认关闭（`VOICEVERSE_COMMUNITY_POST_ENABLED`）；软删+下架位；
9. **schema 真源**：新表入 Python metadata（只读映射）+ PostLike 按新键重写 + 0 行断言 `as_sql` 判定。

## 5. 组长拍板建议（16 项，已采纳折中值）
