# 02 · 功能规划

> 原则：M1~M2 先把"说得好"闭环跑通，M3 再加"唱得准"，社交/社区类按最小实现。

## 功能模块清单

### 用户端（Web，Vue）

| # | 模块 | 说明 | 优先级 |
|---|---|---|---|
| 1 | 注册/登录/学习档案 | 注册、入学测试（口语水平初评）、学习目标标签 | P0 |
| 2 | 场景扮演对话 | AI 数字人模拟生活/工作/学习场景，多轮对话，DeepSeek 驱动 | P0 |
| 3 | 口语评测 | 流式录音 → ASR 转写 → 发音/语法/流利度评分 → 即时反馈 | P0 |
| 4 | 发音纠正建议 | 音素级错误定位 + 正确示范（TTS）+ 改进建议 | P0 |
| 5 | 英文歌练唱 | 选歌 → 歌词/旋律展示 → 跟唱 → 逐句音准节奏评分 | P1（特色） |
| 6 | 个性化推荐 | 内容推荐（兴趣/相似/拓展）、协同过滤、水平预测模型 | P1 |
| 7 | 学习计划生成 | 个性化练习计划、每日任务 | P1 |
| 8 | 可视化报表 | 成绩趋势、雷达图、薄弱维度分析、导出 | P1 |
| 9 | 学习社区（最小版） | 打卡、分享成绩卡片、简单话题区 | P2（可砍） |
| 10 | 数据埋点 | 点击率/完成率/互动率/跳出率统计（检查点指标） | P1 |

### 运营/管理端（最小版）

| # | 模块 | 说明 | 优先级 |
|---|---|---|---|
| 11 | 用户管理 | 用户列表/禁用 | P1 |
| 12 | 场景/歌曲库管理 | 对话场景模板、歌曲与 LRC 词库维护 | P1 |
| 13 | 评价数据看板 | 整体使用指标（完成率、互动率等） | P2 |

## 明确要**砍掉/简化**的功能（避免范围失控）

- ❌ 3D 数字人、口型驱动（SadTalker 等需 GPU）：用 2D 头像 + 语音播放替代
- ⚠️ 移动端 App（Kotlin/Object-C）：Web 端响应式优先，App 作为后续扩展（docx 要求的技术栈里保留，不砍不实现）
- ❌ 完整社交社区（聊天、私信）：只做打卡与成绩卡片分享
- ⚠️ Java 工单/管理后端：按 docx 要求用 Java（Spring Boot）实现，但**最小化范围**（用户管理、场景/歌曲库 CRUD、评价看板即可）

## 关键路径依赖

```
M2 口语闭环:  录音 → ASR → 发音评分 → LLM 场景回应 → TTS → 前端 UI
M3 唱歌闭环:  选歌(LRC) → 录音 → 基频提取 → DTW对齐 → 逐句评分 → 报表
M3 推荐:      行为埋点 → 协同过滤/水平预测 → 推荐接口 → 前端展示
```
