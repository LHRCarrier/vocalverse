# 语音链路审计-自动化测试脚本思路

> 配套文档：《语音链路现状与风险清单-采集模板与执行框架》
> 本文给出 **38 个检查项的自动化采集脚本思路**（Python / Shell），含核心代码骨架、输出约定与安全红线。
> 脚本为**参考模板**，部署到独立审计环境后按实际接口改造；不改业务代码、不落库、不触碰现有文档。

---

## 0. 总体设计

### 0.1 目录规划（审计环境内）

```
audit/
├── config.yaml          # 端点、阈值、黄金语料路径（不含任何密钥明文）
├── golden/              # 黄金语料：asr_wer.json / ise_score.json / tts_cases.json
├── scripts/             # 各检查项脚本
│   ├── common.py        # 公共函数：json_result / percentiles / 脱敏
│   ├── s_a01_health.py ... s_c04_capacity.py
├── results/             # 每脚本输出一个 JSON（按 check_id 命名）
├── reports/             # report.py 合并 results → CSV / Markdown 台账
└── logs/
```

### 0.2 公共约定

- **只读优先**：巡检类脚本对被测系统只做调用与读取；容灾演练类必须人工审批后单独执行。
- **密钥不落盘**：配置中只允许 `env:变量名` 引用，脚本内不打印、不写日志、不进入结果 JSON；结果中一律脱敏（显示 `****`）。
- **统一输出**：每个脚本输出一个 JSON：

```python
# common.py 核心
import json, time

def json_result(check_id, ok, value, threshold, detail, ts=None):
    return {
        "check_id": check_id,          # 如 ASR-A04
        "ok": ok,                      # True / False
        "value": value,                # 实测值（数字或摘要字符串）
        "threshold": threshold,        # 阈值描述
        "detail": detail,              # 脱敏后的补充说明（证据路径等）
        "ts": ts or time.strftime("%Y-%m-%d %H:%M:%S"),
    }

def percentiles(xs, ps=(50, 90, 95, 99)):
    xs = sorted(xs); n = len(xs)
    return {f"p{p}": round(xs[min(n - 1, int(n * p / 100))], 3) for p in ps}
```

- 依赖：`requests`（或 `aiohttp`）、`jiwer`、`numpy`、`scipy`、`cryptography`、`PyYAML`；环境需可访问被测端点与模型目录。

### 0.3 安全红线（硬性）

1. 任何脚本**禁止**输出密钥明文、音频样本内容、用户数据。
2. 压测类脚本默认在**预发环境**或**生产低峰期**运行，先做 1 并发冒烟。
3. 容灾演练 / 流量切换类脚本需要工单审批，演练后立即回切。
4. 结果 JSON 与台账只归档**脱敏摘要 + 证据路径**。

## 1. 可用性类脚本（A 维度）

### S-A01 服务健康检查与成功率（ASR-A01 / TTS-A01 / ISE-A01 / C-05）

**思路**：定时调用 `/healthz` 与少量业务冒烟请求，统计成功率与错误码分布；可并行探测多实例。

```python
# s_a01_health.py（骨架）
import requests, time
from common import json_result, percentiles

ENDPOINTS = {"ASR": "https://asr.internal.example/healthz",
             "TTS": "https://tts.internal.example/healthz",
             "ISE": "https://ise.internal.example/healthz"}

def check(component, n=200, interval=0.1):
    codes, lat = [], []
    for _ in range(n):
        t0 = time.perf_counter()
        try:
            r = requests.get(ENDPOINTS[component], timeout=5)
            codes.append(r.status_code); lat.append(time.perf_counter() - t0)
        except Exception:
            codes.append(0); lat.append(5.0)          # 0 = 连接失败
        time.sleep(interval)
    ok_rate = codes.count(200) / n
    fivexx = sum(1 for c in codes if c >= 500) / n
    return {"ok_rate": round(ok_rate, 4), "fivexx_ratio": round(fivexx, 4),
            "latency": percentiles(lat)}, ok_rate >= 0.999 and fivexx < 0.001
```

**输出判定**：`ok_rate ≥ 99.9%` 且 `5xx < 0.1%` 为通过；否则告警/风险。

### S-A02 时延分位数（ASR-A02 / ISE-A02 共用）

**思路**：用固定短音频（10s）与长音频（60s）各跑 N 次，分别统计 TTFT 与尾包时延的分位数；TTFT 从请求发出到首个识别片段返回计时。

```python
# s_a02_latency.py（骨架：短音频路径 + client 注入）
def measure(client, audio_path, rounds=50):
    ttft, total = [], []
    for _ in range(rounds):
        t0 = time.perf_counter()
        first, done = client.recognize_stream(audio_path)   # 注入被测客户端
        ttft.append(first - t0); total.append(done - t0)
    return {"ttft": percentiles(ttft, (50, 95)), "total": percentiles(total, (50, 95, 99))}
```

**判定**：流式 ASR TTFT P50 ≤ 300ms / P95 ≤ 800ms；ISE 10s 音频 P50 ≤ 2s / P95 ≤ 5s。

### S-A03 并发阶梯压测（ASR-A03 / TTS-A03 / ISE-A03）

**思路**：并发数 1→5→10→20→50 阶梯加压，每档跑固定轮数，记录吞吐、错误率、时延；找到错误率越过 0.5% 的临界并发，比对配额余量。

```python
# s_a03_concurrency.py（骨架：线程池阶梯）
from concurrent.futures import ThreadPoolExecutor
import time
from common import percentiles

def ramp_test(client, audio, levels=(1, 5, 10, 20, 50), per_level=50):
    report = {}
    for n in levels:
        errs, lats = 0, []
        def one(_):
            t0 = time.perf_counter()
            try:
                client.recognize(audio); return time.perf_counter() - t0
            except Exception:
                return None
        with ThreadPoolExecutor(max_workers=n) as ex:
            for r in ex.map(one, range(per_level)):
                if r is None: errs += 1
                else: lats.append(r)
        report[n] = {"ok_rate": round((per_level - errs) / per_level, 4),
                     "latency": percentiles(lats) if lats else None}
    return report
```

**判定**：错误率 < 0.5% 的最大并发 vs 业务峰值并发，余量 ≥ 30%；TTS 额外观察长文本队列积压（从队列监控指标取）。

### S-A04 WER / CER 回归（ASR-A04）

**思路**：黄金语料 `[{audio, ref}]` 逐条调用被测 ASR，用 `jiwer` 计算 CER/WER，输出均值、分位与劣化对比（与上期基线比）。

```python
# s_a04_wer.py（骨架）
import jiwer, json
from common import json_result

def run(golden_path, client, baseline_cer=0.05):
    cases = json.load(open(golden_path, encoding="utf-8"))
    cers = []
    for item in cases:
        hyp = client.recognize(item["audio"])
        cers.append(jiwer.cer(item["ref"], hyp))        # 中文主口径用 CER
    avg_cer = sum(cers) / len(cers)
    ok = avg_cer <= 0.05 and (avg_cer - baseline_cer) < 0.005
    return json_result("ASR-A04", ok, round(avg_cer, 4), "CER ≤ 5%，劣化 < +0.5pt",
                       f"样本 {len(cers)} 条，基线 {baseline_cer}")
```

**注意**：黄金语料需覆盖近场/带噪/远场分场景；只算总体均值会掩盖场景劣化，建议按场景分组输出。

### S-A05 RTF 测算（ASR-A05 / TTS-A05 / ISE-A05）

**思路**：用 `ffprobe` 取音频时长，测被测服务处理总耗时，RTF = 耗时 / 音频时长；流式场景取分片粒度 RTF。

```python
# s_a05_rtf.py（骨架）
import subprocess, time

def audio_duration(path):
    out = subprocess.check_output(
        ["ffprobe", "-v", "error", "-show_entries", "format=duration",
         "-of", "csv=p=0", path])
    return float(out)

def rtf_for(client, audio_path, rounds=10):
    dur = audio_duration(audio_path)
    rtfs = []
    for _ in range(rounds):
        t0 = time.perf_counter(); client.process(audio_path)
        rtfs.append((time.perf_counter() - t0) / dur)
    return {"rtf_avg": round(sum(rtfs) / len(rtfs), 3), "rtf_p95": sorted(rtfs)[int(len(rtfs) * 0.95)]}
```

**判定**：流式 ASR RTF ≤ 0.3；TTS 实时 ≤ 0.5 / 批量 ≤ 0.1；ISE ≤ 0.5。

### S-A06 TTS 首包与完成时延（TTS-A02）

**思路**：短句（≤ 20 字）与长句（≥ 200 字）各 N 次，测「请求→首个音频块」与「请求→完整音频」两个时延。

```python
# s_a06_tts_latency.py
def measure_tts(client, text_short, text_long, rounds=30):
    out = {}
    for label, text in (("short", text_short), ("long", text_long)):
        ttft, done = [], []
        for _ in range(rounds):
            t0 = time.perf_counter()
            first, full = client.synthesize(text)        # 返回(首块,完成)时刻
            ttft.append(first - t0); done.append(full - t0)
        out[label] = {"ttft_p50": percentiles(ttft)["p50"],
                      "ttft_p95": percentiles(ttft)["p95"],
                      "done_p95": percentiles(done)["p95"]}
    return out
```

### S-A07 TTS 合成质量：客观近似 + 抽样试听（TTS-A04）

**思路**：MOS 无法纯自动，采用「客观指标 + 人工抽样」双层：
1. 客观层：对固定文本集合成音频，跑无参考指标（如 `UTMOS`、`DNSMOS`）输出均值与逐条异常清单；
2. 人工层：脚本随机抽取 K 条合成音频生成试听清单，评审打 MOS 分，与客观分交叉核对。

```python
# s_a07_tts_mos.py（客观层骨架，UTMOS 为模型化预测器，需单独部署）
def objective_mos(client, cases, predictor):
    scores = []
    for item in cases:
        wav = client.synthesize(item["text"])[1]
        scores.append(predictor.score(wav))             # 返回 1-5 预测分
    return {"utmos_avg": round(sum(scores) / len(scores), 3), "samples": len(scores)}
```

**判定**：UTMOS 均值 ≥ 3.8 且相对基线劣化 < 0.1；人工 MOS ≥ 4.0；异常样本回放复核。

### S-A08 ISE 评分一致性（ISE-A04）

**思路**：黄金语料 `[{audio, ref_text, expert_total, expert_dims}]` 跑被测 ISE，计算总分与分项的相关性（Pearson / Spearman）、MAE，并检测系统性偏差（均值差、按分数段分组）。

```python
# s_a08_ise_consistency.py（骨架）
import numpy as np
from scipy.stats import pearsonr, spearmanr

def score_consistency(expert, system):
    pearson_r, _ = pearsonr(expert, system)
    spearman_rho, _ = spearmanr(expert, system)
    mae = np.mean(np.abs(np.asarray(expert) - np.asarray(system)))
    bias = np.mean(np.asarray(system) - np.asarray(expert))   # 系统性偏差
    return {"pearson_r": round(pearson_r, 4), "spearman_rho": round(spearman_rho, 4),
            "mae": round(mae, 3), "mean_bias": round(bias, 3)}
```

**判定**：Spearman ≥ 0.85、MAE ≤ 5（百分制）；分项相关性 ≥ 0.8 需逐维度输出；`mean_bias` 过大（如 > 3 分）提示系统性松紧问题。

## 2. 密钥类脚本（K 维度）

### S-K01 密钥有效期核验（ASR-K01 / TTS-K01 / ISE-K01）

**思路**：从三处取到期时间——本地证书文件、云平台 Key（API 查询）、配置中心（接口/人工确认）；统一换算剩余天数。

```python
# s_k01_expiry.py（证书部分骨架）
from datetime import datetime
from cryptography import x509

def cert_days_left(pem_path):
    with open(pem_path, "rb") as f:
        cert = x509.load_pem_x509_certificate(f.read())
    expiry = cert.not_valid_after
    return (expiry - datetime.now(expiry.tzinfo)).days
```

```bash
# 云平台 Key 到期（示例，输出脱敏：只显示 UserName/状态/最后使用，不显示 Secret）
aliyun ram ListAccessKeys --UserName svc-asr-prod
aws iam list-access-keys --user-name svc-asr-prod
```

**判定**：剩余 > 30 天通过；< 30 天告警；< 7 天 P1；已过期 P0。

### S-K02 密钥权限范围核验（ASR-K02 / TTS-K02 / ISE-K02）

**思路**：查询 IAM/ACL 中该服务账号的策略与绑定资源，检查三点：是否含管理员级权限、是否绑定 IP 白名单、是否跨环境复用（同一 Key 出现在多环境配置）。


**判定**：任一管理员级权限 / 无白名单 / 跨环境复用 → 风险（P1 起）。

### S-K03 硬编码与泄露扫描（ASR-K03 / TTS-K03 / ISE-K03）

**思路**：两层扫描——当前工作区静态扫描（gitleaks）+ Git 历史泄露扫描（`git log -S`）；结果只报告文件路径与命中模式，**绝不输出密钥本身**。

```bash
# 静态 + 历史扫描
gitleaks detect --source . --log-opts="--all" --report-format json --report-path results/s_k03_gitleaks.json

# 兜底正则（常见 AK/SK、私钥块、高熵串；命中即人工复核）
grep -rnE "(AKIA[0-9A-Z]{16}|sk-[A-Za-z0-9]{20,}|-----BEGIN (RSA |EC )?PRIVATE KEY-----)" \
  --include="*.py" --include="*.js" --include="*.go" \
  --include="*.yaml" --include="*.yml" --include="*.env*" . || echo "no plaintext key pattern"

# 历史提交中的疑似 Key（输出 commit 与文件名即可）
git log --all -p -S "AKIA" --name-only --format="%h %s" | head -50
```

**判定**：任何命中 → P0（吊销 + 轮换 + 排查泄露面）；0 命中通过。另需人工确认：.env 不在 VCS 中（`git check-ignore .env`）、.env.example 仅占位符。

## 3. 模型类脚本（M 维度）

### S-M01 模型文件 MD5 批量校验（ASR-M01 / TTS-M01 / ISE-M01）

**思路**：读发布 manifest（`{相对路径: {md5, version}}`），对模型目录批量算 MD5 比对；不一致即 P0。大文件用分块读取，避免一次性载入内存。

```python
# s_m01_md5.py（骨架）
import hashlib, json, pathlib

def md5_file(path):
    h = hashlib.md5()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):   # 1MB 分块
            h.update(chunk)
    return h.hexdigest()

def verify(manifest_path, root):
    manifest = json.load(open(manifest_path, encoding="utf-8"))
    bad = []
    for rel, meta in manifest.items():
        p = pathlib.Path(root) / rel
        if not p.exists():
            bad.append((rel, "missing")); continue
        if md5_file(p) != meta["md5"]:
            bad.append((rel, "md5-mismatch"))
    return bad
```

**注意**：Windows 审计机可用 `certutil -hashfile <file> MD5` 替代；manifest 本身应受版本控制并校验其自身哈希（防篡改）。

### 5.2 结果合并与台账回填（report.py 思路）

```python
import json, glob, csv

def merge_results():
    rows = []
    for f in sorted(glob.glob("results/*.json")):
        rows.append(json.load(open(f, encoding="utf-8")))
    with open("reports/audit_summary.csv", "w", newline="", encoding="utf-8") as fp:
        w = csv.DictWriter(fp, fieldnames=["check_id", "ok", "value", "threshold", "detail", "ts"])
        w.writeheader(); w.writerows(rows)
    return rows
# 扩展：可将 CSV 转 Markdown 表格回填到台账文档（只改审计产物，不改业务文档）
```
