# 03 · 技术选型

## 总体架构

```
Vue 前端 (Web)
   │  REST + WebSocket(流式)
   ▼
Java 后端 (Spring Boot) —— 按课题文档负责：系统架构、工单管理、业务接口
   │  (场景/歌曲库 CRUD、用户管理、工单、报表接口)
   ▼
Python 服务 (FastAPI) —— 按课题文档负责：数据处理、模型部署
   ├── LLM Agent 编排层    DeepSeek API：场景扮演、多轮对话、评分报告生成
   ├── 语音管线            ASR / TTS / 发音评分 / 唱歌评分
   ├── 推荐与预测          协同过滤 + 口语水平预测(Scikit-learn, CPU)
   └── 模型训练            发音评分微调(PyTorch/TensorFlow，可云 GPU)
   数据层                  PostgreSQL + Redis(会话缓存)
```

> 注：按课程 docx 案例 #7 的技术栈要求（后端 Python + Java、前端 Vue、模型训练 PyTorch/TensorFlow、推荐 Scikit-learn）。Python 服务与 Java 服务通过内部 REST 通信；移动端 App（Kotlin/Objective-C）作为后续扩展，本期以 Web 为主。

## 语音模块选型（关键决策）

| 能力 | 基线方案（免费/低成本） | 自研加分方案 | 成本 |
|---|---|---|---|
| ASR 转写 | Whisper API 或 faster-whisper small/medium（本地 CPU 可跑） | 微调 WeNet/Whisper（可选） | ¥0 |
| TTS 合成 | Edge-TTS（免费）或 Azusre/火山 API | 语音克隆（进阶，本期不搞） | ¥0 |
| 发音评分 | 讯飞评测 API（免费额度）：发音/流利度/完整度 | **wav2vec2 微调**（speechocean762 数据集，音素级标注） | 基线 ¥0；自研约 ¥50~110 |
| 唱歌评分 | pyin/crepe 基频提取 + DTW 时间对齐（CPU） | 音准分数 + 节奏偏差 + 歌词逐句对齐 | ¥0 |
| 语音活动检测 | webrtcvad / Silero VAD | - | ¥0 |

**路线建议**：先跑通 API 基线（1 周内），答辩前若时间允许用 speechocean762 微调 wav2vec2 作为自研亮点（GPU 20~40 小时，4090 一次性 ¥50~110）。

## LLM 场景扮演 Agent

- 模型：DeepSeek（API，便宜，中文能力强）
- 设计要点（可复用组内 Agent 经验）：
  - 系统提示词：角色设定（咖啡馆店员/面试官/旅游向导…）+ 难度档 + 纠错风格
  - 工具调用：`fetch_scene`, `save_attempt`, `generate_report`（评分报告结构化）
  - 流式输出：SSE 推送文本，TTS 排队合成
  - 多轮管理：Redis 存会话，超时回收

## 数据与部署

- 数据：PostgreSQL（用户/会话/评分记录/歌曲库）；Redis（会话与缓存）
- 部署：Docker Compose（java-api + python-api + web + db）
- 敏感信息：API Key 只进 `.env`（gitignore），公开仓库严禁提交密钥
