## 里程碑排期（6 周）

### M1 · 项目骨架（第 1 周）

- [ ] 仓库协作规范落地（PR 流程、commit 规范）
- [ ] 前端骨架：Vue + Vite + 路由 + 录音组件（MediaRecorder）
- [ ] Python 服务骨架：FastAPI + PostgreSQL 建模 + .env 管理
- [ ] Java 管理端骨架：Spring Boot + 用户/场景/歌曲库 CRUD 接口
- [ ] 语音三件套联调：ASR / TTS / 发音评分单个接口可用（先 API 基线）

### M2 · 口语 MVP（第 2-3 周）

- [ ] 场景扮演对话：DeepSeek Agent 多轮 + 流式 + TTS 播放
- [ ] 发音评分报告：转写 + 评分 + 错误定位 + 示范音频
- [ ] 注册/入学测试/学习档案
- [ ] Web 端完整口语练习流程（录音→评分→建议→再练）

### M3 · 唱歌 + 智能（第 4-5 周）
- [ ] 歌曲库 + LRC 歌词管理（管理员端）
- [ ] 跟唱录音 → 基频提取 → DTW 对齐 → 逐句音准/节奏评分
- [ ] 协同过滤推荐 + 口语水平预测模型（Scikit-learn, CPU）
- [ ] 行为埋点：点击率/完成率/互动率/跳出率看板
- [ ] 可视化报表（趋势、雷达图、导出）
- [ ] （可选）wav2vec2 微调发音评分 —— 租云 GPU 20~40h 完成

### M4 · 联调与答辩（第 6 周）
- [ ] 性能优化（响应时间、并发）
- [ ] 演示数据 + 演示脚本
- [ ] 答辩材料：PPT、系统截图、视频
- [ ] 复盘：本轮生成的 `docs/` 文档同步更新
