### 5.3 手动验收清单（演示前逐项签字）

- 场景闭环：进页 → 选卡 → 开场 → 录音 ≤15s → **首声 ≤POC 实测值** → 徽章迟到回填 → 教练笔记/覆盖度 → 8 轮收尾 → 报告 → 再练（进阶套）
- 救场：8s 不录 → 提示卡 → 重说 → 继续；连续 2 轮差 → AI 代说；救援轮不计互动率（核对表勾）
- defense：粘贴摘要 → 生成耗时实测（记录）→ 6 问 → 等级/命中 → 报告 → 重练第二遍
- 指标：完成/互动/跳出/回答率在报表可选（先用 SQL 核对，M3 看板）
- 降级：Redis 断（degraded 启动）、ise 断（"未评测"）、LLM 断（备用台词）、edge-tts 断（无声字幕）
- 安全：注入论文不泄露 system 提示；/audio 跨用户越权 403；全站扫描无 v-html 渲染模型/用户文本
- docs/13 §8 验收表（token 零硬编码/对比度/断点/空态/动效 ≤2）
