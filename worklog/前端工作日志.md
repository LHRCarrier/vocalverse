## 2026-09-04 导航栏 Dock 磁性放大交互 + 设计系统一致性调整

### 背景与产出

将 React Bits 的 `<Dock />` 组件效果适配到静态首页导航栏（无需 React 依赖），并对全站交互色彩、文字对比度、版式层级做系统性统一：

| 交付 | 文件 | 要点 |
|---|---|---|
| Dock 磁性放大导航 | `index.html` / `styles.css` / `common.js` | `.navbar-dock` 容器 + `.dock-item` 标记；原生 `requestAnimationFrame` 按鼠标水平距离逐项 `scale`（默认 1 → 放大 1.2，作用距离 180px，锚定 `center top` 向下展开）；`@media (hover:none)` 触屏降级；键盘 focus/blur 高亮 |
| 悬浮提示标签 | `common.js` / `styles.css` | JS 从按钮原有文字自动生成 `.dock-label` 气泡（顶部下方弹出），无 HTML 重复文案 |
| 导航链接四态配色 | `styles.css` | 默认 / 悬停 / 按下 / 激活 四态明确色值 + `:focus-visible` 描边；Sign In 按钮补充按下反馈 |
| 放大比例与间距优化 | `common.js` / `styles.css` | 放大上限 1.35→**1.2**、距离 200→180；`.desktop-links` 间距 0→0.5rem（768–1024 平板 0.25rem / ≥1280 大屏 0.75rem）；放大项 `z-index:3` 置顶避免拥挤感 |
| 交互态改为「文字同色边框」 | `styles.css` | 导航链接悬停/按下/聚焦：取消颜色与背景变化，显示 `1px` `--neutral-700` 边框（预留透明边框防布局抖动）；Sign In 按钮显示白色边框；聚焦关闭默认绿色 outline（追加独立规则覆盖后置可访问性块） |
| 设计 token 统一 | `styles.css` | 新增 `--font-sans/serif`、`--fs-xs…4xl` 字号阶梯、`--lh-*` 行高、`--fw-*` 字重、`--text-primary`、`--score-deep`、`--focus-ring` |
| WCAG 2.1 AA 对比度修复 | `styles.css` | `--neutral-500` #737373→**#52525b**（页灰底 ≈4.1:1 不达标 → ≥6:1）；浅底橙色小号文本改用 `--score-deep` #C2410C（card-change / post-action.liked / badge-orange）；`intro-subtitle` 改 `--neutral-700` |
| 版式层级统一 | `styles.css` | 全局 `h1–h6` 无衬线 + 700 + `line-height:1.2`；`features/dashboard/intro` 系列标题接入字号阶梯；`body` 走 `--font-sans` + 抗锯齿渲染优化 |
| 全局交互态补齐 | `styles.css` | `button:disabled`、表单 `:disabled`、`::placeholder` 颜色、输入框焦点统一 `--focus-ring`、链接基色 |
| CTA 悬停变绿修复 | `styles.css` | 全局 `a:hover` 设置主色会覆盖 `.cta-button` 白字 → `.cta-button:hover { color:#fff }` 显式保持 |

### 关键点

1. **Dock 从 React 到原生复刻**：页面为静态 HTML（无 React/motion 依赖），组件源码仅作行为参考；用 `rAF` 逐帧 `scale` + CSS transition（`.18s cubic-bezier`）模拟弹簧放大，效果一致且零依赖。
2. **交互规范统一为「边框而非变色」**：按用户要求，导航交互元素交互态不再改变颜色/背景，改为显示与文字同色的边框（nav 链接灰边、Sign In 白边）。
3. **放大不改布局**：dock 项用 `transform: scale`（不占布局位）+ `transform-origin: center top` 向下展开，贴合顶部 fixed 导航；`z-index` 提升放大项覆盖相邻项。

### 验证

- 本地 `python -m http.server 8900` 提供静态预览，浏览器实测桌面渲染：绿色主题 / 导航 / Hero 视频 / 卡片全部正确应用，控制台**无 JS/CSS 报错**；Computed 校验 `--primary=#047857`、Sign In 背景 `rgb(4,120,87)` 与白字。
- 桌面全页截图存档（`...trae\screenshots\vocalverse-desktop-index-fullpage.png`）。
- CSS token 落地逐项 grep 校验（`--score-deep` / `--focus-ring` / `--neutral-500:#52525b` 等全部命中，`styles.css` 正常返回 200）。

### 踩坑记录

1. **全局 `a:hover` 覆盖显式颜色元素**：通用链接变绿规则（`(0,1,1)`）优先级高于 `.cta-button` 白字（`(0,1,0)`），悬停时按钮文字变绿——需对带显式颜色的组件逐一显式覆盖。
2. **focus-visible 规则被后置同优先级块覆盖**：`.nav-link:focus-visible{outline:none}` 与「可访问性焦点样式」块同为 `(0,2,0)`，后者在后会覆盖前者；必须在该块之后再追加一条独立规则才能关闭绿色描边。
3. **浏览器自动化无法模拟移动端视口**：`window.resizeTo` 被自动化浏览器锁定，390px 移动截图无法产出；移动端响应式仅能静态核对媒体查询（640/768/1024/1280 断点），未能逐屏截图。
4. **dock 类标记仅落在 index.html**：其余 5 个功能页共享 `styles.css/common.js` 但未加 `dock-item`/`navbar-dock` 类，导航放大与四态边框交互暂不生效，已向用户说明待同步。

### 验证

2. **浏览器自动化取值**：`browser_evaluate` 返回 `{content:[{text}]}` 包装，须取 `.content[0].text`；多语句脚本常返回 undefined，宜拆成单表达式逐项断言。

| 交互增强 | `styles.css` + 内联 JS | Toast 通知系统；按钮功能补全（登录/录音模拟/唱歌评分/打卡/点赞评论/管理 CRUD）；涟漪、脉冲、骨架屏、进度条过渡 |
| 导航栏三阶段优化 | `styles.css` | ① 与搜索框视觉区分 ② 透明背景 + Logo 间距 ③ 移除全部边框、fixed 贴合视口 |
| 注释中文化 | 全部文件 | CSS / HTML / JS 注释统一中文 |
| 多页面拆分 | `styles.css` / `common.js` / 7 个 HTML | 首页用 `<a>` 导航跳转，页面间链接校验全通过 |
| Admin 移除 + 功能介绍重构 | 5 个功能页 | 删除 admin.html 与全部 admin 样式；每页按「设计目的 / 核心功能 / 主要特性 / 使用场景」四段式重构，无交互操作元素 |
| 滚动入场动画 | `reveal.js` | IntersectionObserver（threshold 30%、unobserve 防抖、不支持时降级），支持 up/zoom/left/right/fade 多方式 |
| 卡片交互优化 | `styles.css` | 链接卡片 hover（上移/主色阴影/顶部高亮条/图标动效）+ active 按压回弹 + focus-visible + `@media (hover:none)` 触摸适配 + `prefers-reduced-motion` |
| 卡片文案 | `index.html` | 卡片标题/描述/按钮改中文「查看详情 →」，明确导航指向 |

### 关键点

1. **整页视频背景曾实施后回退**：按用户偏好恢复为「仅首屏视频」，功能卡片区保持浅灰底。
2. **多页面拆分保留共享资源**：视觉一致性靠 `styles.css` 设计 token + `intro-*` 通用布局类保证，各页仅内联专属 JS。
3. **滚动动画与 hover 并存**：reveal 隐藏态 transform 与卡片 hover transform 通过「增强规则置于 reveal 之后 + 动画结束后清除 transition-delay」解耦。

### 验证

浏览器实测：5 张卡片滚动进入视口 30% 后全部触发 reveal；hover 时 computed 显示 `translateY(-3px)` / 主色阴影 / 边框变色 / 高亮条展开；tap-highlight 为透明；`(hover:hover)` 桌面正确匹配；控制台无 JS 错误。

### 踩坑记录

1. **整页视频背景方案返工**：fixed 整页背景虽实现，但用户要求保持原设计，完整回退——避免过度设计，先与用户确认再大改。
2. **PowerShell 批量注入时 `` `n `` 变字面量**：单引号字符串中 `` `n `` 不转义，注入成字面 `` `n ``，需用 `Replace` 修复为真实换行并逐页校验。
3. **IntersectionObserver 旧浏览器兼容**：不支持时降级为直接显示全部卡片，保证功能可用。
4. **reveal-active 首次断言为 0**：实为卡片未达视口 30% 阈值，继续滚动后 5/5 触发——验证时需滚动到位再断言。
5. **admin 死样式残留**：删除 admin.html 后 styles.css 仍留 `.admin-*` / `.ticket-*`，逐处清理并 grep 确认零引用。
6. **reveal 与 hover 的 transform 冲突**：hover 规则写在 reveal 之后以覆盖隐藏态；`transitionend` 后清 `transition-delay`，避免影响后续 hover。
