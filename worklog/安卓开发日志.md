## 2026-09-04 手机端当日交付：Android APK 可装可跑 + 移动端三页真形态 UI 上线（原型 ui-concept-design/app）

- **决策（组长授权「自己决策」）**：目标 = 今天有能跑的 App 端；形态 = **Capacitor 8.5 远程 URL 型壳**加载局域网全栈（docker compose，nginx 同源反代），Web 前端零改动复用、后端零改动；iOS 因无 Mac 列后；PWA 最小化兜底（顺还 docs/22 轴线E B5 欠账）。
- **交付物**：① `apps/mobile`（Capacitor 工程 + Android 平台，compileSdk/targetSdk 36）；② `app-debug.apk`（≈3.9MB，`server.url` 指向局域网，cleartext 放行，AndroidManifest 显式 `usesCleartextTraffic`）；③ 全栈 docker compose 5 服务（readyz=0）；④ PWA（manifest+图标+theme-color）；⑤ **移动端真形态 UI 三页**（源自 `F:\WorkingL\uic-release\ui-concept-design\examples\app\{home,speaking,report}.html` 原型，tokens 同源）：`/m/home` 今日学习（问候/打卡/统计/分段/今日会话=真实场景数据+点线时间轴）、`/m/chat/:sceneId` 场景对话（气泡+语言点 chip+录音大按钮，逻辑移植 PracticeView：创建会话/SSE/音频队列/救援计时）、`/m/report` 评分报告（深紫评分卡+四维统计+逐句；?reportId 接真实口语报告，无则形态演示标注）；`'/'` 与登录后默认落点改 `/m/home`（骨架演示页保留 `/demo`）。
- **验证（模拟器 Android 15 · 无窗口 headless）**：APK 安装启动 → 服务连通（Python ✓/Java ✓）→ **App 内登录 demoadult → /m/home（"Good morning, 成年中级" + 场景列表真实数据）→ /m/chat（AI 开场 + 救援卡 + 录音按钮）→ /m/report**，三页截图留档（`local/final-*.png`，gitignored）；
- **门禁**：apps/web lint 0 / typecheck ✓ / vitest 19 ✓ / build ✓（生产构建预览子树零残留）；python/java CI 未触及（契约零 diff）。
- **踩坑（按仓库惯例记录）**：
  1. 本机 Windows schannel 沙箱无凭据 → 全部下载走 node（OpenSSL）与 `--use-system-ca`；keytool printcert 只打印不校验链，别当验证手段；
  2. **Gradle 8.14.3 发行版下载 PKIX 失败**（CDN 链路被拦）→ 本地分发缓存方案：node 下载 zip → `distributionUrl=file://` 装一次 → 把完整 dist 复制到官方 URL 的 cache hash 目录 → wrapper 配置文件**回退官方地址入库**（本机路径不入库）；
  3. `npx cap sync` 必须在 `apps/mobile` 根执行（android/ 子目录会报「platform not added」且配置不烘焙）；改 `server.url` 后必须 sync → assembleDebug；
  4. **WebView 里 `adb input keyevent 4`（返回）= 退出应用**，别拿它关键盘；WebView 输入用坐标常因键盘弹出偏移 → 改用 **CDP 直驱**（`setprop debug.webview 1` + `adb forward ... webview_devtools_remote_<pid>` + Runtime.evaluate）；
  5. JWT access 15min 过期后页面 401 属预期；**refresh 轮换**导致「诊断性 refresh 未持久化 → bootstrap 清 token」的循环——验证时走 App 自己的登录页，别手动拼 localStorage；
  6. 新页面样式「没生效」两次：① `mobile-uic.css` 忘了 import（Vite 独立 css chunk 不随 index.html）；② 部署后 WebView 缓存旧 index.html → CDP `Network.setCacheDisabled(true)` + `Page.reload(ignoreCache)` 强刷；
  7. 重启电脑后局域网 DHCP 变了（10.133.33.185→192.168.1.3）→ 配置/README 同步更新；**IP 属环境动态值，文档已标注「以实际局域网为准」**。
