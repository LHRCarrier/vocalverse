# BUG：跟唱面板滚动后白屏（`position:absolute` 挂在随内容长高的容器上）

- **发现**：2026-09-10 · 唱歌模块七路拷问（A 路 Playwright 实测命中 + D 路静态审计；主代理复跑脚本复核）。
- **修复**：2026-09-10 · 执行人：AI 代签（正式署名待组长确认）。
- **影响面**：`/m/sing` 跟唱面板（`MobileSingView.vue` + `styles/mobile-sing.css`）——**只要歌单滚动过，点歌即白屏**：面板顶部（关闭钮 / 歌名 / 歌词 / 「听参考旋律」/「开始跟唱」）全部落在视口**上方**，用户除"反向滚回顶部"外无控件可用（"整个页面卡住"的真机体感来源之一）。纯前端（零后端/契约影响）。

## 复现

1. 打开 `/m/sing`，把歌单向下滚动（实测 `scrollY=1175`，文档高 2019）；
2. 点任一歌曲行 → 打开跟唱面板；
3. 实际（修复前）：屏幕是**纯灰空白页**；实测几何 —— `sheet {top:-1175, height:2019}`、`head {bottom:-1102}`、`startBtn {top:-822}`、`refBtn {top:-878}`（视口高 844）。

## 根因

```css
/* 修复前 */
.m-sing-sheet { position: absolute; inset: 0; z-index: 30; }
```

- `.m-sing-sheet` 的包含块是 `.u-phone`（`mobile-uic.css:74-92`：`position: relative; min-height: 100vh`，**随内容长高、可远超视口**）；
- `inset: 0` ⇒ 面板尺寸 = **整个文档高度**，且起点在文档顶部；
- 页面滚到 1175 时，面板"顶部 1175px"被滚出视口 → 可见区域恰是面板中段的空白处；
- 同时面板内部 `__body{flex:1; overflow-y:auto}` 因面板本身已"高过视口"而**不产生内部滚动**，用户也无法用面板内滚动找回控件。

## 修复

1. **视口锚定**（照抄仓内 `.u-tabbar` 的既有写法 `mobile-uic.css:2070-2079`）：
   ```css
   .m-sing-sheet {
     position: fixed; left: 50%; transform: translateX(-50%);
     top: 0; bottom: 0; width: 100%; max-width: 480px; z-index: 30;
     display: flex; flex-direction: column;
   }
   .m-sing-sheet__head { flex: none; }         /* 头部不被压缩，body 才滚动 */
   ```
   宽度与 `.u-phone`（`max-width:480px` 居中）同源；高度由视口上下界决定 → `__body` 恢复内部滚动。
   依据：docs/35（App 端 UI 迭代 SOP：容器 bottom ≤ 视口高；"页面总高超视口"为已登记典型陷阱）、docs/31:36（硬规则 4：safe-area）。
2. **顶部安全区**：`__head` padding 改 `calc(14px + env(safe-area-inset-top)) 16px 14px`（与 `.u-drawer` 同款约定 `mobile-uic.css:2774`），刘海屏不被状态栏压住。
3. **背景滚动锁**（`MobileSingView.vue`）：`watch(sheetOpen)` 打开置 `document.body.style.overflow='hidden'`、关闭还原；`onUnmounted` 兜底还原（面板开着直接离开页面时不得把整页锁死）。仓内此前无锁滚约定，本页局部实现并注释说明。

## 踩坑

1. **`absolute + inset:0` 在"随内容长高的容器"里≠全屏**：要按**视口**全屏必须 `fixed`（或把滚动容器改成视口高）；判断依据是"包含块是谁"，不是"看起来铺满"。
2. **happy-dom 没有排版引擎**：这类几何缺陷在单测里**测不出来**，所以补了"样式契约守卫"（读 CSS 断言关键属性）作为可入 CI 的回归网，几何验证仍靠 Playwright 脚本（本轮已复跑）。
3. **`fixed` 的隐形杀手是祖先的 `transform/filter/will-change`**：会导致 `fixed` 退化为相对该祖先定位（同样的白屏会复现）。本次先核对了祖先链（`App.vue` 无 `<Transition>` 包裹、`.u-phone` 无 transform）并用真浏览器几何数据确认 `top:0`，没有只凭"改了 fixed"就宣布修好。
4. **body 级副作用必须成对还原**：滚动锁在"卸载"路径容易漏 → 会把整页永久锁死；用例里同时覆盖"关闭还原"与"卸载还原"，测试间还需复位（面板是 body 级状态，跨用例会串）。
5. **面板打开时背景可滚**会暴露"面板下方是歌单"的穿帮；锁滚 + 视口锚定是一套（只做一半仍会露馅）。
