# BUG：发音抽样句窗方向反（`start − offset`）→ 占权重 0.3 的发音分算在静音/别的句子上

- **发现**：2026-09-10 · 唱歌模块七路拷问（B 路后端口径探针 + F 路文档口径对账，**两路独立指向同一处**）；主代理读码复核。
- **修复**：2026-09-10 · 执行人：AI 代签（正式署名待组长确认）。
- **影响面**：`app/sing/service.py:_pron_sample_lines`（发音抽样）——跟唱**发音维度（综合权重 0.3）**；所有 `offset_ms ≠ 0` 的演唱（用户整体早/晚起唱，真机实测 offset = **2272ms**）。ICC/可比性受损：同一段演唱的发音分不可复现（同一录音重复评分结果一致，但含义是"别处的分数"）。

## 复现

1. 录一首**整体晚起唱 1.5s** 的歌（offset_ms = +1500）；
2. 抽样句（默认前 3 句）走 ISE 发音评分；
3. 实际：切片窗口取 `[start−1500, end−1500)` → 落在用户录音的**静音段/上一句尾音**上（合成验证：正确窗 rms=0.3536，代码窗 rms=**0.0**）；
4. 结果：`lines[i].pron_score` 与"该句唱得如何"无关，且 `offset` 越大错得越远（2×offset）。

## 根因

同仓存在**明确登记的时间轴不变式**：`用户时间轴 = 参考时间轴 + offset_ms`（`app/audio/sing.py:725-730` docstring；docs/06 §9.4 口径表）。

- 评分侧遵守：`sing.py:1071-1078` → `win_start = a["start_ms"] + offset_ms`（并按 `window_scale(bpm_ratio)` 缩放句长，BUG-4）；
- 抽样侧写反：`service.py:309` → `_slice_wav(wav, line.start_ms - offset, line.end_ms - offset)`。

即**同一模块内两处方向相反**。旧注释（"BUG-5/归属"等）未覆盖此处；且 `test_sing_service.py` 的 Fake 打分器与 pipeline 桩 `alignment.offset=0` → **单测结构上看不见**（0 − 0 = 0 + 0），这也是它能长期存活的原因。

## 修复

`app/sing/service.py`：

```python
offset = float(result.alignment.get("offset_ms") or 0.0)
scale = window_scale(result.alignment.get("bpm_ratio"))     # 与评分侧同源（BUG-4）
...
win_start = float(line.start_ms) + offset                    # ← 由 − 改 +
win_end = win_start + max(1.0, (float(line.end_ms) - float(line.start_ms)) * scale)
seg = await _slice_wav(wav, win_start, win_end)
```

- 与 `app/audio/sing.py:1071-1078` **逐行同口径**（时间轴 + 句长缩放），代码注释写明依据：docs/06 §9.4（时间轴不变式 + BUG-4 句窗缩放）、docs/21 §3.6、docs/10 §4.3；
- docs/06 §9.4 增「发音抽样句窗口径修复（2026-09-10 · P0）」小节；docs/21 §3.6 评分口径行补「抽样句窗按用户时间轴切」；
- **未改动**：抽样句数（默认前 3）、「weak 句优先」（docs/06 D3 写了但未实现，属另案 P1，本次不动以免混入语义变更）。

## 踩坑

1. **同一不变式在两个文件里各写一遍，就一定会有一处写反**：方向类 bug（时间轴、坐标、正负号）应优先抽公共映射函数（本处已用同一 docstring 表述，但代码仍是两份 → 建议 P2 抽 `ref_window_to_user(line, alignment)` 供两侧共用）。
2. **Fake 空心化会掩盖整类缺陷**：offset=0 的假打分器让"±offset"永远等价——回归用例必须**构造非零 offset**（本例即用 offset=1500 判别）。
3. **审计的"双路印证"价值**：代码侧（B）看方向、文档侧（F）查不变式，两路独立命中同一行代码，可信度远高于单路。
