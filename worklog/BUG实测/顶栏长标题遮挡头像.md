# 顶栏长标题遮挡左上角头像（抓取公版书把正文塞进标题）

> 归档日期：2026-09-10 · 发现人：组员手机实测（组长转达）· 模块：`apps/web` `MobileTopBar` / `mobile-uic.css`

## 复现

部分抓取的公版书把正文塞进了章节标题（如 `CHAPTER I. Down the Rabbit-Hole Alice was beginning to get
very tired of sitting by her sister on the bank, and of having nothing to do`），进阅读器后顶栏标题过长
→ **左上角账户头像被标题文字盖住**（截图取证：`local/shots/topbar-before.png`，复现页
`local/topbar-repro.html`，量测脚本 `local/cdp-measure.mjs`）。

几何量测（无头 Chrome CDP，390×1250，修复前）：

```
CASE1 短标题  ava=[16.0,52.0] title=[156.8,233.2]  overlapAva=false
CASE2 超长标题 ava=[16.0,52.0] title=[ 26.0,320.0]  overlapAva=true   ← 标题盒左沿 26 < 头像右沿 52
CASE3 长标题+2 个右按钮 ava=[16.0,52.0] title=[26.0,272.0] overlapAva=true
```

## 根因

`mobile-uic.css` 顶栏用 `display:grid; grid-template-columns: 1fr auto 1fr;`：

- 中间 `auto` 轨道按标题 **max-content** 撑开（`white-space: nowrap` 不换行）；
- 左右 `1fr` 轨道的隐式最小值是 `auto`，但 `.u-topbar__left` 写了 `min-width: 0`
  → 左轨道被压到 **0 宽**；
- 头像 `36px; flex: none` 溢出自己的轨道，而标题 `<h1>` 在 DOM 中靠后（同层后绘制）
  → 标题文字画在头像上。

## 修复

`apps/web/src/styles/mobile-uic.css`（一行轨道定义 + 一行标题 min-width）：

```css
.u-topbar {
  grid-template-columns: minmax(min-content, 1fr) minmax(0, auto) minmax(min-content, 1fr);
}
.u-topbar__title { min-width: 0; }
```

- 左右轨道最小 = **min-content**（头像/右侧按钮永不被压缩）；
- 中间轨道 `minmax(0, auto)`：短标题仍按内容居中（与修复前完全一致），长标题收缩到可用宽度走省略号。

## 验证

无头 Chrome CDP 量测（`local/topbar-repro.html` 4 个用例 × 3 种视口），`overlapAva/overlapActs` 全 false、
无横向溢出（`phoneScrollW == viewportW`）：

| 用例 | 修复前 390px | 修复后 390px |
|---|---|---|
| CASE1 短标题 | title=[156.8,233.2] 居中 0 | title=[156.8,233.2] 居中 0（**零回归**） |
| CASE2 超长标题 | title=[26,320] **overlap=true** | title=[62,320] overlap=false，省略号，中心偏 -4px |
| CASE3 长标题 + 2 右按钮 | title=[26,272] **overlap=true** | title=[62,272] overlap=false，中心偏 -28px |
| CASE4 无空格超长串 | title=[26,320] **overlap=true** | title=[62,320] overlap=false |

320px / 430px 视口同样 4 用例全 false。截图：`local/shots/topbar-before.png` / `topbar-after.png`。
门禁：`pnpm lint` / `typecheck` / `test:run`（137 passed）/ `build` / `check-bundle.mjs` 全绿。

## 踩坑

1. **纯 CSS 布局 bug 在 happy-dom 里测不出来**（无排版引擎，`getBoundingClientRect` 全 0）
   → 改用无头 Chrome + CDP `Runtime.evaluate` 量包围盒做客观判定；肉眼看截图容易漏掉「盒子重叠但
   文字刚好没压上」的边界情况，数字判定可复现、可回归。
2. **`1fr` 的隐式最小值是 `auto`，会被 item 的 `min-width:0` 覆盖**：轨道最小值必须显式写成
   `min-content` 才能保证头像列不被压缩 —— 只给 item 加 `min-width` 是修不掉的。
3. **真居中与标题可用宽度不可兼得**：右侧按钮 2 个时（宽 92px）标题盒中心左偏 28px。本次取舍为
   「不遮挡 + 标题尽量宽」优先（`minmax(0, auto)` 让标题吃满剩余空间，而不是 `1fr` 三等分只剩 112px）。
