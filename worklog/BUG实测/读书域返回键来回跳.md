# 读书域返回键来回跳：书详情 ⇄ 阅读器 出不去（导航历史栈成环）

> 归档日期：2026-09-10 · 发现人：组员手机实测（组长转达）· 模块：`apps/web` 移动端读书域

## 复现

手机 App（或浏览器移动视口）路径：

```
书房 /m/bookshelf → 点一本书 → 书详情 /m/books/:bookId → 「开始阅读」→ 阅读器 /m/reader/:chapterId
→ 点右上角「离开」→ 回到书详情 → 再点「离开」→ 又回到阅读器 → 反复来回，退不出这本书
```

自动化复现（修复前必失败）：`apps/web/src/views/mobile/__tests__/MobileReadingBack.test.ts`

```
× 阅读器「离开」→ 书详情；书详情「离开」→ 书架（不再来回跳）
  → expected '/m/reader/7?book=1' to be '/m/bookshelf'
× 冷启直达书详情（无上一条历史）时「离开」回退到书架，而不是卡死
  → expected '/m/books/1' to be '/m/bookshelf'
```

## 根因

两个页面的「离开」语义不对称，把历史栈压成了环：

| 页面 | 修复前 | 效果 |
|---|---|---|
| `MobileReaderView.vue:235` | `@back="router.push('/m/books/' + bookId)"` | **新增**一条历史（阅读器 → 书详情） |
| `MobileBookDetailView.vue:58` | `@back="router.back()"` | **回退**一条历史（书详情 → 阅读器） |

历史栈演化：

```
[书架, 详情, 阅读器]            ← 阅读器点「离开」
[书架, 详情, 阅读器, 详情]      ← 书详情点「离开」→ back() 回到阅读器
[书架, 详情, 阅读器]            ← 阅读器再点「离开」→ push 详情 …
```

两页互为对方的「上一页」，形成 2 页循环（浏览器历史栈永远退不到书架）。

次要缺陷：书详情用 `router.back()`，**冷启/深链直达**（history 无上一条）时 `back()` 空转，
页面卡死（只能点头像开抽屉绕出去）。

## 修复

新增 `apps/web/src/composables/useMobileBack.ts`：统一「返回」= 有上一条历史就 `router.back()`，
否则 `router.replace(fallback)`（永不 push，历史栈深度单调不增）。

```ts
const goBack = useMobileBack('/m/bookshelf')            // 书详情
const goBack = useMobileBack(bookId ? `/m/books/${bookId}` : '/m/bookshelf')  // 阅读器
```

- `MobileBookDetailView.vue`：`@back="goBack"`（fallback = 书房）
- `MobileReaderView.vue`：`@back="goBack"`（fallback = 本书详情）

修复后路径：阅读器「离开」→ 书详情（back）→ 书详情「离开」→ 书房（back）→ 书房「离开」→ 学习页（原设计不变）。

## 踩坑

1. **memory history 测不出真实行为**：`useMobileBack` 依赖 `history.state.back`（vue-router 4 的
   `createWebHistory` 维护它），而 `createMemoryHistory` 的 `state` 恒为 `{}` → 用 memory history 写的
   测试会**永远走 fallback 分支**，修复前后都「绿」，等于没测。必须 `createWebHistory()`（happy-dom 对
   同源 popstate 有实现：`BrowserFrameNavigator` 同源历史项直接派发 popstate）。
2. **只点一次返回断言不出这个 bug**：无论 push 还是 back，第一次点「离开」都落在书详情；
   必须连点两次，第二次断言（应到书架）才暴露环。写回归测试时要把「循环的第二圈」写进去。
3. **同类隐患仍在**：其他页面把固定页当返回用（如书房 `router.push('/m/learn')`、笔记/生词本同理）
   不构成环，但会多压一条历史 —— 接入系统返回手势后表现为「多弹一次」。本次只修读书域，
   不改组长拍板的「学习组功能页离开 = 回 /m/learn」语义（改动面控制）。
